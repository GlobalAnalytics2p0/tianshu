# 雪刃照孤城資料夾說明

本資料夾保存《雪刃照孤城》的正式章節、作者人格、人物架構、伏筆管理與素材。

## 檔案用途

- `第NN章 *.txt`：正式小說正文，只能放沉浸式白話繁中小說。
- `核心靈魂檔案.md`：謝聽寒的人格、刀感與冷硬武俠語氣。
- `作者思路.md`：沈照夜、程聽雪與孤城舊案伏筆。
- `人物架構.md`：主要人物、舊案與江湖/官面衝突。
- `每日寫作狀態.md`：每次續寫前必讀的最新局勢與下一章方向。
- `伏筆事件台帳.md`：照骨刀路、第三個學刀的人、暗道與官面壓制。
- `主角圖片素材/`：沈照夜與程聽雪相關視覺素材。
- `影片/`、`有聲書/`：媒體規劃資料，非日更預設產物。

## 續寫定位

這本要讓讀者讀到雪、刀、沉默和尊嚴。爽點不是話多，而是沈照夜出刀、判局、逼問舊案時乾脆有力。感情線慢慢藏在共同冒險與互相拆穿裡。
