# 雪刃照孤城素材說明

本資料夾集中保存《雪刃照孤城》的作者人格、人物架構、伏筆管理、圖像素材與影音規劃。正式小說正文放在同層的 `文章/`，影音成品只在需要製作時放入根層 `有聲書/`、`影片/`。

## 素材檔案用途

- `核心靈魂檔案.md`：謝聽寒的人格、刀感、冷硬白話與江湖尊嚴。
- `作者思路.md`：沈照夜、程聽雪、孤城舊案與刀債走向。
- `人物架構.md`：主要人物、舊案壓力、江湖與官面衝突。
- `每日寫作狀態.md`：最新局勢、下一章刀口與關係壓力。
- `伏筆事件台帳.md`：照骨刀路、第三個學刀的人、暗道與官面壓制。
- `反思.md`：資深讀者對拖、悶、忍而不爆與感情線失焦的直接批評。
- `風格規則.md`：謝聽寒專屬句法、刀場節奏、反同質化規則。
- `圖像/主角圖片素材/`：沈照夜與程聽雪相關視覺素材。
- `有聲書/`、`影片/`：聲音、畫面與媒體方向；目前只保留規劃。

## 續寫定位

這本的章節要像雪地裡慢慢逼近的一刀。少說廢話，但不能少情緒；每次克制都要換來局部翻盤或更沉的舊債。
