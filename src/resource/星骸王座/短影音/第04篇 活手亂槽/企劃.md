# 第04篇 活手亂槽

## 定位

主打第13章後形成的短影音強符號：一群普通人的手，反咬一個靠認手殺人的制度。

## 規格

- 長度：70-90 秒。
- 平台：Shorts、Reels、TikTok。
- 視覺：東槽白日、濕木板、多隻手、灰頁、周嬸、阿福、孩子。
- CTA：留言「活手」或「亂槽」。

## 0-3 秒鉤子

```text
他們要認一隻手
沈曜叫來了一整條巷子的手
```

## 旁白草稿

```text
第七欄要認一隻手。
沈曜叫來了一整條巷子的手。

這不是熱血口號。
在《星骸王座》裡，敵人最可怕的地方，是他們會把活人的痕跡洗乾淨，重新寫成一個能被處理的名字。

手紋、乾板、白布、灰頁。
它們用很普通的東西，做很冷的事。

但沈曜看懂了一點。
只要他們靠乾淨辨認，那就把現場弄髒。
只要他們只想要一隻手，那就讓所有人都伸手。

周嬸、阿福、洗布婦、孩子，全都把手按上去。
一個殺人的白日流程，第一次被普通人弄到失準。

這不是大招。
這是活人一起反咬命運。
```

## 分鏡

| 時間 | 畫面 | 字幕 |
| --- | --- | --- |
| 0-3s | 一隻手按上乾板 | 他們要認一隻手 |
| 3-12s | 多隻手突然湧入畫面 | 他叫來整條巷子的手 |
| 12-28s | 白布、灰頁、東槽 | 活人痕跡會被洗乾淨 |
| 28-45s | 沈曜看向乾板 | 靠乾淨辨認，就把現場弄髒 |
| 45-70s | 周嬸、孩子、洗布婦按手 | 普通人一起讓流程失準 |
| 70-90s | 木板滴水，字被抹開 | 活手亂槽 |

## 圖像需求

- 9:16 主圖：濕木槽上密密麻麻都是不同人的手，遠處沈曜站在雪光裡。
- 需要「群體」感，不能只有主角帥照。
