# 第02篇 死法預告

## 定位

主打「變強不是獎勵，而是先看見死亡」。這是最適合玄幻受眾的強概念。

## 規格

- 長度：60-75 秒。
- 平台：YouTube Shorts、Reels。
- 視覺：少年、雪線、不同死法殘影、星核、手指抓雪。
- CTA：導向「第一章有聲書」或官網。

## 0-3 秒鉤子

```text
別人的修煉是升級
他的修煉是死亡預告
```

## 旁白草稿

```text
別人的修煉，是突破、升級、開掛。
沈曜的修煉，是先看見自己怎麼死。

一次可能死在雪地。
一次可能死在黑棺旁。
一次可能被自己最相信的星光帶進死路。

你以為這是詛咒。
但對一個被流放到邊境、連命都快保不住的人來說，知道死法，至少代表還有一點點時間可以改。

《星骸王座》不是一個天才一路碾過去的故事。
它是少年每次被命運推進死局，都硬把那個局拆開一條縫。

如果你喜歡冷硬玄幻、死亡預視、少年逆命，這本可以試一章。
```

## 分鏡

| 時間 | 畫面 | 字幕 |
| --- | --- | --- |
| 0-3s | 死亡殘影三連閃 | 修煉前，先看見死法 |
| 3-12s | 沈曜跪在雪地，手指抓雪 | 他沒有開局無敵 |
| 12-25s | 黑棺、星核、巡星司影子 | 他只有下一種死法 |
| 25-42s | 星光破碎，畫面回到少年眼睛 | 知道會死，就還能改 |
| 42-60s | 雪線中向前走 | 每一次活下來，都是逆命 |
| 60-75s | 書名與閱讀入口 | 試讀《星骸王座》 |

## 圖像需求

- 9:16 複合圖：同一個少年身後有三種半透明死法殘影。
- 需要有雪、星光、黑棺三個符號，但不要塞太滿。
