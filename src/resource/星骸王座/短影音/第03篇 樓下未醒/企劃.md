# 第03篇 樓下未醒

## 定位

把《星骸王座》的第七欄恐怖規則包裝成微短劇感鉤子。這支可以吸引懸疑、恐怖、短劇受眾，不只玄幻讀者。

## 規格

- 長度：75-90 秒。
- 平台：TikTok、Reels、Shorts。
- 視覺：深夜樓下、冷光、門縫、白紙、星砂、安靜街巷。
- CTA：留言「樓下醒了嗎」或導向第七欄線。

## 0-3 秒鉤子

```text
最恐怖的不是有人敲門
是你家樓下太安靜
```

## 旁白草稿

```text
最恐怖的不是半夜有人敲門。
是你家樓下太安靜。

在《星骸王座》裡，有一個詞叫「樓下未醒」。
它不是鬼故事。
它是一套殺人流程最喜歡的現場。

沒有人咳嗽。
沒有人點燈。
沒有人吵架。
沒有人能證明你剛剛還活著。

所以沈曜第一次真正反擊，不是拔刀。
他把一整條巷子叫醒。

孩子哭，老人罵，鍋灶響，藥味衝出門。
一個乾淨的死局，突然變得又髒又吵。

這就是《星骸王座》最狠的地方。
它不是只寫怪物，它寫一個制度最怕普通人醒著。
```

## 分鏡

| 時間 | 畫面 | 字幕 |
| --- | --- | --- |
| 0-3s | 黑夜門縫，字幕硬切 | 樓下太安靜 |
| 3-15s | 冷巷、沒燈、白紙落地 | 這是殺人流程最愛的現場 |
| 15-30s | 紙上出現「樓下未醒」 | 沒人能證明你還活著 |
| 30-50s | 沈曜回頭，巷子開始點燈 | 他反擊的方法很土 |
| 50-70s | 鍋灶、孩子、周嬸、藥味快切 | 把整條巷子叫醒 |
| 70-90s | 白紙被雨水弄髒 | 制度最怕普通人醒著 |
