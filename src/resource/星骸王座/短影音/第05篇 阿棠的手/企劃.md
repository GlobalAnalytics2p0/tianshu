# 第05篇 阿棠的手

## 定位

用阿棠吸女性角色、關係張力與 BookTok/Reels 情緒受眾。重點不是戀愛糖，而是「她不是被救，她主動伸手進死局」。

## 規格

- 長度：65-85 秒。
- 平台：Instagram Reels、TikTok、Threads 延伸文。
- 視覺：阿棠手腕舊疤、藥門、乾板、沈曜與阿棠並肩判局。
- CTA：留言「阿棠」或「她會不會回頭」。

## 0-3 秒鉤子

```text
她不是等人救的女主
她把自己的手伸進死局
```

## 旁白草稿

```text
阿棠不是等人救的女主。
她知道那隻手可能會被認出來。
她也知道，伸出去以後，自己可能再也退不回藥門。

但她還是伸了。

《星骸王座》裡，沈曜和阿棠的關係不是一上來就告白。
是兩個人都知道前面有坑，還是會替對方留一條能活的路。

她會看藥味，會判門路，也會在沈曜太冷的時候把人拉回來。
而現在，第七欄盯上的，可能不只是沈曜的姓。
還有阿棠那隻舊手。

如果一個制度要把你的名字寫回死局。
你是躲起來，還是親手把它弄亂？
```
