# 第06篇 玄幻短榜

## 定位

借 BookTok/Reels 常見的推薦與榜單格式，不只推單章，而是把《星骸王座》包裝成「你現在可以開始追的冷硬玄幻」。

## 規格

- 長度：45-65 秒。
- 平台：TikTok、Reels、Shorts。
- 視覺：書名大字、主角圖、三個賣點卡、網站入口。
- CTA：收藏、轉給喜歡玄幻的人。

## 0-3 秒鉤子

```text
如果你看膩了無敵開局
試試這本被命運先判死刑的玄幻
```

## 旁白草稿

```text
如果你看膩了無敵開局，可以試試《星骸王座》。

它的主角不是天選之子。
他是被流放、被盯上、被命運先寫進死局的人。

第一個賣點：他撿到一顆會說謊的星核。
第二個賣點：每次變強之前，他都會先看見一種死法。
第三個賣點：他不是靠大招解決一切，而是把普通人的燈、灶火、手和聲音都變成反擊。

這本的爽感不是一路碾。
是你看著一個少年，每次只差一點就死，卻每次都把命運拆開一寸。

喜歡冷硬玄幻、少年逆命、長線懸疑，可以先收這本。
```

## 分鏡

| 時間 | 畫面 | 字幕 |
| --- | --- | --- |
| 0-3s | 書名與主角圖硬切 | 看膩無敵開局？ |
| 3-12s | 沈曜雪地剪影 | 被命運先判死刑 |
| 12-24s | 星核特寫 | 賣點 1：會說謊的星核 |
| 24-36s | 死法殘影 | 賣點 2：變強前先看死法 |
| 36-50s | 巷子燈火與活手 | 賣點 3：普通人一起反擊 |
| 50-65s | 官網/YouTube/書名 | 收藏這本冷硬玄幻 |

- 9:16 榜單卡：主角居中，三個賣點以動態卡片依序出現。
- 可用既有主角圖裁切成封面，再補雪粒、星核、字幕動態。
