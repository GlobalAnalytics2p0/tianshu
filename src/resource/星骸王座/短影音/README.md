# 星骸王座短影音賽道

## 短影音總監定位

短影音總監負責把《星骸王座》從長篇連載、有聲書與官網閱讀，轉成 TikTok、YouTube Shorts、Instagram Reels、Threads、Facebook Reels 可用的垂直短內容。

製作新短影音前，先讀 `短影音製作規則.md`。該檔記錄第 01 篇試作後沉澱出的文案、語音、轉場、授權音樂、導流與 QA 規則。

目標不是重述章節，而是用角色、世界觀、情緒議題與爆款短劇語法，把路人拉進「想知道沈曜怎麼活下去」的第一個問題。

## 核心策略

- 影片長度優先做 60-90 秒，主格式 9:16，1080x1920。
- 1080x1920 是短影音主檔規格：YouTube Shorts 官方接受直式影片並標註 Shorts 最高 1080p；TikTok 官方 in-feed 規格建議直式 9:16 且最低 >=540x960。跨 Shorts、TikTok/抖音式 feed、Instagram Reels 與 Facebook Reels 時，以 1080x1920 做圖片、字幕與 FFmpeg 輸出，不用最低規格製作。
- 前 1 秒必須有大字鉤子、人聲第一句或強畫面，不做慢開場。
- 每支只講一個可轉發的問題：命運、死法、被抹名、冷硬少年、阿棠的手、普通人反抗制度。
- 用人聲旁白帶節奏，字幕做高對比短句，不用整段章節朗讀。
- 不和章節一對一綁定；每支可以像獨立短劇預告、角色剪影、讀者推薦、心理測驗或爆款題材榜單。
- 視覺優先使用既有角色圖與霜河主視覺，再逐步補生成 9:16 專用分鏡圖。

- 每篇資料夾內保留 `企劃.md`。

- 大型影片與音檔不要提交 Git；文字腳本、分鏡、字幕草稿、製作紀錄可以提交。
