# 星骸王座

玄幻長篇，作者顧夜燼。這本的核心不是升級展示，而是邊境少年在星核謊言、罪籍追殺與街坊求生中，一次次把死局咬開半寸。

## 目錄

- `文章/`：正式章節正文，由 `manifest.json` 指向載入。
- `素材/`：作者人格、人物、伏筆、風格規則、圖像與影音製作規劃。
- `有聲書/`：本機音訊輸出與候選成品；大型音訊不提交。
- `影片/`：橫式影片輸出與章節製作資料；大型影片不提交。
- `短影音/`：已建立的直式短影音製作線。

## 寫作抓手

每章先讓沈曜遇到一個能傷到人、飯、藥、名或活路的具體麻煩，再讓星核與沈氏舊線只露一點影子。爽點要來自「他明知會付代價，仍然多活一步並保住一個人」。
