# 影片規劃

本檔保留《星骸王座》的可重用影像方向與已驗證製作規格；實際章節成品放在根層 `影片/`。

- 主軸：邊境寒夜、墓地、星象、低火光。
- 封面關鍵詞：少年背影、碎裂星核、霜河、黑藍金色調。
- 旁白節奏：前段壓低，中段加快，尾段在揭露死法畫面時收緊。
- 每集標題沿用小說章名，避免額外劇透。
- 影片底圖方向：優先使用霜河、黑棺、星核、雪夜、守墓棚等章節相關圖像做慢速動態與硬字幕；不要把本系列預設成泛用跑步或遊戲背景。
- 正式影片規格：720p、Edge YunJhe `+0%` / `-2Hz`、字幕不超過兩行，旁白永遠是主聲道，並套用柔化人聲 EQ/limiter。
- 背景音規則：正式章節統一使用雨聲白噪音，不使用旋律音樂、爐火或其他會搶聽覺注意力的背景。
- 章節影片資料直接保存在 `src/resource/星骸王座/影片/<章節名>/`，不再另建 top-level `video-resource`。
- 影片不得繞過有聲書。每章正式影片製作或重製前，先確認 `src/resource/星骸王座/有聲書/<章節名>/` 有同章獨立有聲書音檔，且該音檔、影片 TTS 腳本、字幕與根層 `文章/<章節名>.txt` 來自同一版正文。
- 若 MP4 已存在但獨立有聲書缺失，該章狀態仍是「影片已出、媒體流程未完成」。補做順序必須是：最新正文 -> 有聲書 -> 影片 TTS/source -> 字幕 -> MP4。
- 2026-06-07 修正方向：字幕必須使用同次 TTS 產生的句級/詞級時間資料，不再用平均字數推估；圖片改為固定圖定時切換，不使用上下晃動或 pan/zoom；完整影片每張背景圖約停留 3-5 分鐘。
