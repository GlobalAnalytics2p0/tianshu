# 有聲書規劃

本檔保留《星骸王座》的可重用聲音方向；實際音訊成品放在根層 `有聲書/`。

- 聲線方向：偏低沉、年輕但帶疲憊感的男聲。
- 配樂方向：少量弦樂與風雪環境音，不要滿鋪。
- 演繹重點：沈曜內斂、阿棠克制、星核語氣要像故意把真話說反。
- 每章結尾保留半拍停頓，讓未解問題留下回味。

## 影片前置規則

- 《星骸王座》每一章要製作長篇影片前，必須先產出或驗證同章的正式有聲書音檔，位置為 `src/resource/星骸王座/有聲書/<chapter title>/`。
- 影片使用的 narration/TTS 腳本必須與根層 `文章/<chapter title>.txt` 完全對齊；若正文更新，先重做有聲書，再重做影片與字幕。
- 不得只因 `影片/<chapter title>/output/*.mp4` 已存在就視為有聲書完成。MP4、字幕、影片 source 與獨立有聲書音檔是不同交付物，需分別檢查。
