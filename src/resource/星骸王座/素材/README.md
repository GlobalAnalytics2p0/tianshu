# 星骸王座素材說明

本資料夾集中保存《星骸王座》的作者人格、人物架構、伏筆管理、圖像素材與影音製作紀錄。正式小說正文放在同層的 `文章/`，影音成品放在根層 `有聲書/`、`影片/`，短影音另由根層 `短影音/` 管理。

## 根目錄分類

- `../文章/`：正式小說正文，只能放沉浸式白話繁中小說，並由 `manifest.json` 指向載入。
- `../有聲書/`：本機音訊輸出與候選成品；大型音訊檔不提交 Git。
- `../影片/`：後續影片輸出或本機成品；大型影片檔不提交 Git。
- `./`：所有 `.md` 規劃文件、圖像素材與製作紀錄集中放這裡。

## 素材檔案用途

- `核心靈魂檔案.md`：顧夜燼的人格、中心思想、玄幻爽文語氣。
- `作者思路.md`：沈曜、阿棠與邊境長線伏筆。
- `人物架構.md`：主要角色性格、主線壓力與敵友關係。
- `每日寫作狀態.md`：每次續寫前必讀的最新局勢與下一章方向。
- `伏筆事件台帳.md`：星核、沈氏、古墓、巡星司等線索的回收節奏。
- `反思.md`：資深讀者對流程感、爽點、長線與人味的直接批評。
- `風格規則.md`：顧夜燼專屬句法、邊境逆命感、反同質化規則。
- `圖像/主角圖片素材/`：沈曜與阿棠相關視覺素材。
- `圖像/首頁爆款素材/`：首頁今日爆款或榜首版位使用的小說專屬主視覺。
- `有聲書/`：聲音設定、製作規則與逐章製作紀錄。
- `影片/`：影片方向、素材使用規則與製作規劃。

## 續寫定位

這本的核心是邊境少年逆命。爽點要來自沈曜在寒地、罪籍、星核謊言與體制追殺中，用判斷和狠勁多活一步。大真相不能太快揭；每章要讓讀者看到他更難殺，也更接近被抹掉的沈氏祕密。
