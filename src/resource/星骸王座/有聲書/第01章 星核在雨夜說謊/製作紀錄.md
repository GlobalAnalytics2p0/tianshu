## 聲音判斷

這一版先採用年輕、偏冷、低情緒起伏的台灣中文男聲，對應沈曜被邊軍追殺、身體失血、星核冷聲介入的壓力感。朗讀節奏不做過度戲劇化，讓黑棺、星核與雨夜追兵保留懸疑。

## 已知限制

- macOS `say` 可作為本機第一版，但情緒細節、停頓與角色差異仍不如專業台灣華語 TTS 或真人錄音。
- 若後續接入雲端 TTS，優先測試更自然的台灣華語男聲，並保留冷調、克制、微疲憊的敘事方向。
- 音訊成品屬大型衍生檔，依目前規則保留在本機並由 `.gitignore` 忽略，不納入 Git commit。

## 正式版重產計畫

目標改用高品質台灣華語 TTS。若使用 OpenAI speech generation，先測 `cedar` 聲線與 `0.95` 語速，並透過 `scripts/generate-openai-audiobook.mjs` 產生 `OpenAI-cedar.zh-TW.m4a`。重產前需要設定 `OPENAI_API_KEY`，否則無法用雲端模型產音。

```bash
OPENAI_API_KEY=... node scripts/generate-openai-audiobook.mjs \
  --novel '星骸王座' \
  --chapter-title '第01章 星核在雨夜說謊' \
  --chapter-file 'src/resource/星骸王座/第01章 星核在雨夜說謊.txt' \
  --voice cedar \
  --speed 0.95 \
  --output 'src/resource/星骸王座/有聲書/第01章 星核在雨夜說謊/星骸王座-第01章-星核在雨夜說謊-OpenAI-cedar.zh-TW.m4a'
```
