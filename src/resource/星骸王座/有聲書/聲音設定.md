# 星骸王座有聲書聲音設定

## 旁白方向

- 語言腔調：繁體中文／台灣華語優先。
- 正式聲線目標：自然、耐聽、低壓的台灣華語男聲；不可有明顯系統語音、客服播報或新聞主播感。
- 本機流程驗證聲線：`Eddy (Chinese (Taiwan))`，僅供粗稿與管線測試，不視為可上線版本。
- 聲音目標：偏低、冷靜、年輕男性旁白，帶一點疲憊感；語調要像商業有聲書，不要過度戲劇化。
- 語速目標：每分鐘約 155-165 字感，保留懸疑與寒地壓力。
- 情緒曲線：前段壓低、黑棺異常時收緊、星核說話時略帶冷諷、結尾保留半拍懸念。

## 角色演繹重點

- 沈曜：冷、窮、能忍，句尾不要太飄，重點放在壓住情緒。
- 阿棠：克制、乾淨、判斷快，語氣不要甜。
- 星核：像故意把真話說反，帶一點不舒服的笑意。
- 邊軍與追殺者：粗硬、壓迫，但不要誇張吼叫。

## 製作規則

- 正文來源永遠使用章節 `.txt`，不要複製一份新的正文到有聲書資料夾。
- 可在朗讀稿前加書名與章名，但不要改動小說正文。
- 音檔輸出放在本資料夾下對應章節資料夾；音訊副檔名已被 `.gitignore` 忽略，不應提交到 Git。
- 正式版優先使用高品質 TTS。若使用 OpenAI speech generation，透過 `scripts/generate-openai-audiobook.mjs` 切段、合併並輸出 `.m4a`。
- 若沒有雲端 TTS API key，不要宣稱音檔可上線；只能標示為本機粗稿。

## OpenAI TTS 建議設定

- 模型：`gpt-4o-mini-tts`
- 聲線優先測試：`cedar`。官方 Speech API 文件列為支援的 built-in voice。
- 語速：先用 `0.95`，避免追殺段過快、伏筆段沒有停頓。
- 切段：預設每段約 1800 字，降低長篇繁中內容超過模型輸入限制的風險。
- 備選方向：若 `cedar` 太硬，改測更溫和但仍低壓的男聲；若角色辨識不足，優先調整 instructions，不要先拆成多角色誇張配音。
- 朗讀指令核心：自然台灣華語、正式有聲書、冷調低壓、追殺段收緊、伏筆段停頓半拍、對白輕微區分但不誇張變聲。

範例指令：

```bash
OPENAI_API_KEY=... node scripts/generate-openai-audiobook.mjs \
  --novel '星骸王座' \
  --chapter-title '第01章 星核在雨夜說謊' \
  --chapter-file 'src/resource/星骸王座/第01章 星核在雨夜說謊.txt' \
  --voice cedar \
  --speed 0.95 \
  --output 'src/resource/星骸王座/有聲書/第01章 星核在雨夜說謊/星骸王座-第01章-星核在雨夜說謊-OpenAI-cedar.zh-TW.m4a'
```

## 2026-06-07 第一版

- 工具：macOS `say` + `ffmpeg`。
- 聲音：`Eddy (Chinese (Taiwan))`。
- 輸出：AAC `.m4a`，單聲道，44.1 kHz。
- 評估：此版本聽感不足，僅保留為管線驗證與時間估算，不作為正式上線音檔。
- 限制：本機系統聲音情緒細節與角色區分有限；正式上架前必須重產高品質 TTS 或採用真人錄音。
