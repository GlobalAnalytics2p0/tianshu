# 大明墨工素材說明

本資料夾集中保存《大明墨工》的作者人格、人物架構、伏筆管理、圖像素材與影音規劃。正式小說正文放在同層的 `文章/`，影音成品只在需要製作時放入根層 `有聲書/`、`影片/`。

## 素材檔案用途

- `核心靈魂檔案.md`：蕭墨臣的人格、工匠流、歷史權謀與白話工理。
- `作者思路.md`：沈墨、顧清棠、南河圖籍與官面謊帳。
- `人物架構.md`：主要人物、河工現場、官場壓力與小人物飯碗。
- `每日寫作狀態.md`：最新局勢、下一章工法驗真與人情代價。
- `伏筆事件台帳.md`：返墨河、第三條河、沈父墨方、周承訓與料帳線索。
- `反思.md`：資深讀者對工序過滿、人味不足、爽點未當眾兌現的直接批評。
- `風格規則.md`：蕭墨臣專屬句法、工法轉白話、反同質化規則。
- `圖像/主角圖片素材/`：沈墨與顧清棠相關視覺素材。
- `有聲書/`、`影片/`：聲音、畫面與媒體方向；目前只保留規劃。

## 續寫定位

工藝不是百科，是證據。每章都要讓尺、墨、榫、河泥、帳冊或料單變成能逼權力露餡的東西，並讓旁邊的小人物看懂這一刀切在哪裡。
