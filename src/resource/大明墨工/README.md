# 大明墨工資料夾說明

本資料夾保存《大明墨工》的正式章節、作者人格、人物架構、伏筆管理與素材。

## 檔案用途

- `第NN章 *.txt`：正式小說正文，只能放沉浸式白話繁中小說。
- `核心靈魂檔案.md`：蕭墨臣的人格、工匠流與歷史權謀語氣。
- `作者思路.md`：沈墨、顧清棠與南河圖籍伏筆。
- `人物架構.md`：主要人物、河工、官場與小人物壓力。
- `每日寫作狀態.md`：每次續寫前必讀的最新局勢與下一章方向。
- `伏筆事件台帳.md`：返墨河、第三條河、沈父墨方、周承訓等線索管理。
- `主角圖片素材/`：沈墨與顧清棠相關視覺素材。
- `影片/`、`有聲書/`：媒體規劃資料，非整點連載預設產物。

## 續寫定位

這本的爽點是小工匠用手藝逼權力露餡。節奏要穩，但不能悶；每章都要讓讀者看見沈墨靠眼、手、尺、墨、帳冊或地勢破掉一點官面謊話。
