# 灰塔觀測者素材說明

本資料夾集中保存《灰塔觀測者》的作者人格、人物架構、伏筆管理、圖像素材與影音規劃。正式小說正文放在同層的 `文章/`，影音成品只在需要製作時放入根層 `有聲書/`、`影片/`。

## 素材檔案用途

- `核心靈魂檔案.md`：霧原的人格、灰塔秩序恐懼與奇幻懸疑語氣。
- `作者思路.md`：艾文、伊芙、班寧、第十三層與承位線。
- `人物架構.md`：主要人物、工務階層、敵友關係與灰塔主線。
- `每日寫作狀態.md`：最新局勢、下一章焦點與可追物。
- `伏筆事件台帳.md`：黑點、鐘聲、負層、父親字跡與被刪名字的回收節奏。
- `反思.md`：資深讀者對悶、冷、流程感與爽點兌現的直接批評。
- `風格規則.md`：霧原專屬句法、留白尺度、反同質化規則。
- `圖像/主角圖片素材/`：艾文與伊芙相關視覺素材。
- `有聲書/`、`影片/`：聲音、畫面與媒體方向；目前只保留規劃。

## 續寫定位

灰塔的恐怖要落在「一個人被制度悄悄改掉」上。每章至少讓一個名字、聲音、工位、窗格或紀錄變得不可靠，再讓艾文用很小的證據把它留住。
