# 灰塔觀測者資料夾說明

本資料夾保存《灰塔觀測者》的正式章節、作者人格、人物架構、伏筆管理與素材。

## 檔案用途

- `第NN章 *.txt`：正式小說正文，只能放沉浸式白話繁中小說。
- `核心靈魂檔案.md`：霧原的人格、灰塔秩序恐懼與奇幻懸疑語氣。
- `作者思路.md`：艾文、伊芙、班寧與第十三層伏筆。
- `人物架構.md`：主要人物與灰塔主線。
- `每日寫作狀態.md`：每次續寫前必讀的最新局勢與下一章方向。
- `伏筆事件台帳.md`：黑點、鐘聲、負一層、父親字跡等線索管理。
- `主角圖片素材/`：艾文與伊芙相關視覺素材。
- `影片/`、`有聲書/`：媒體規劃資料，非整點連載預設產物。

## 續寫定位

這本的爽感不是打爆敵人，而是在規則壓迫下看見破綻。艾文要從被忽略的底層觀測員，慢慢變成灰塔最怕的那種人：記得不該記得的細節，並敢把它們串起來。
