# 凌晨三點的演算法資料夾說明

本資料夾保存《凌晨三點的演算法》的正式章節、作者人格、人物架構、伏筆管理與素材。

## 檔案用途

- `第NN章 *.txt`：正式小說正文，只能放沉浸式白話繁中小說。
- `核心靈魂檔案.md`：陳停雲的人格、都市科技驚悚與冷幽默語氣。
- `作者思路.md`：周祈、林岫與死亡推送伏筆。
- `人物架構.md`：主要人物、平台權力與模型黑箱。
- `每日寫作狀態.md`：每次續寫前必讀的最新局勢與下一章方向。
- `伏筆事件台帳.md`：K-0311、確認者、唐曜、母親公寓等線索管理。
- `主角圖片素材/`：周祈與林岫相關視覺素材。
- `影片/`、`有聲書/`：媒體規劃資料，非日更預設產物。

## 續寫定位

這本的爽點是資訊戰。周祈不能只逃命，他要用工程師腦袋反查模型、權限、定位與人的動機。所有技術都要落到人身上，讓讀者看懂且覺得毛。
