十一點十分還沒到，服務樓一樓的叫號燈先跳了一下。

C 桌亮起來時，沒有人坐在那裡。桌面很乾淨，乾淨到像剛被人用酒精擦過兩遍，連上一位家屬留下的杯圈都不見。周祈看著那張桌，第一反應不是查後台，而是看椅子。

椅子被往右挪了七公分。

這七公分很熟。A 桌不收那晚，前台說只是讓路；B 桌小卡那晚，司機說只是順手；現在 C 桌沒有人，椅子卻先替某個人讓好了位置。

林岫把手機舉起來，鏡頭對準桌腳，不對準人臉。她知道這種場合最容易被說成偷拍鬧事，所以先拍物，再問話。前台小姐站在櫃台後，手指按著熱感印表機，指尖全白。

「補看是什麼？」一個中年男人問。他是 B 桌家屬，剛剛才學會回收單不能亂簽，語氣裡還有怕。

周祈沒有回答得太快。他看見螢幕右下角跳出一行小字：C desk replay window open。這種英文若直接說出來，一樓的人只會更慌。他把那句翻成白話：「它要找一個人，坐到 C 桌，把剛才沒看完的東西補看完。」

「看完會怎樣？」前台小姐問。

「看完，系統就能說你在場。」周祈說，「就像你真的同意它把那頁補上。」

一樓安靜了一下。

安靜很危險。服務樓最會把安靜寫成同意。林岫立刻問：「誰被通知補看？」

沒有人先答。大家都看手機，像怕亮起來的是自己。三秒後，保全老高的手機震了一下。他臉色一垮，把螢幕舉起來。不是簡訊，是服務樓內部群的工作提醒：請協助 C 桌家屬補看，避免情緒阻塞。

「避免情緒阻塞。」林岫冷笑一聲，「這句真客氣，客氣到像準備把人推進去。」

老高嘴角抽了抽。他平時最愛說按流程，今天卻把手機放到桌面上，沒走向 C 桌。他說：「我收到，未執行。」

不是周祈駭進哪裡，而是一個最容易被流程借手的保全，當場把收到和執行分開。前台小姐馬上拿熱感紙印下時間，貼在 C 桌左側：老高收到，未帶人。

叫號燈又跳了一下。

C 桌上方螢幕出現一張模糊的家庭照片。照片只有一秒，立刻被灰色遮住。周祈還是看見了，照片裡有一個孩子坐在餐桌邊，頭髮亂，手裡拿著一支紅色原子筆。

他心口像被人用冷手捏了一下。那不是他父親舊案裡的第一個孩子，卻像同一類現場：讓家屬坐下，看一段似是而非的東西，再把反應收成證據。

林岫看見他的臉色，沒有追問，只把鏡頭轉向螢幕下方的桌牌。桌牌背面黏著一張小便利貼，字很淡：補看後，請家屬自行確認第三頁。

中年男人罵了一句。他不懂第三頁，但懂自行確認。很多壞事都喜歡用自行兩字，彷彿你只要不小心按下去，就再也不能怪別人。

周祈讓所有人先離 C 桌三步。不是為了神祕，是為了拍清楚誰沒坐下。前台小姐拿出白板，在上面寫：C 桌現在空著，任何人未坐。她寫完又自己補一句：補看不是同意。

字不好看，但很有用。

一個老太太忽然說：「那我能不能看？我不怕，我年紀大了。」

周祈看向她。她是先前在 A 桌旁幫忙問過頁數的老太太，熱心，也最容易被借。服務樓最愛這種人，因為他們想替年輕人省一點事。

林岫先開口：「阿姨，妳不怕，不等於它可以用妳。」

老太太愣住，臉有點紅。她想反駁，最後卻低頭看自己手裡的菜袋。袋裡有青菜，有藥，有一只還熱的饅頭。她不是英雄，她只是等得太久，想快點結束。

前台小姐把這句也寫下來：想快點，不代看。

叫號燈第三次跳動，這回 C 桌沒有亮，消防梯方向亮了一盞小綠燈。上一輪留下的名單在梯又被接回來了。周祈走過去，沒上梯，只看梯口地墊。地墊被換過，舊的灰腳印不見了，新的地墊中間有一條壓痕，像有人推輪椅經過。

老高說：「我十分鐘前還看過，沒有這條痕。」

「你能寫嗎？」周祈問。

老高點頭，走回白板前，字寫得比前台小姐還醜：十點五十九分，梯口無輪椅痕；十一點零七分，有痕，未見人。

這句醜字一貼，消防梯小綠燈熄了一秒。普通人自己的工作記憶，終於被用來卡住流程。

可下一秒，林岫的手機收到一條陌生訊息：別讓他再看照片。訊息沒有署名，發件人是一串臨時號。她沒有藏，直接把螢幕給大家看。

周祈看著那行字，沒有立刻判斷是提醒還是誘導。都市黑箱最髒的地方，就是會把好心和陷阱做成同一種口氣。

「先問誰受益。」他說。

前台小姐跟著寫：不看照片，不等於不留證。林岫把照片出現的時間、遮罩顏色、桌牌便利貼和消防梯綠燈全部拍下來，貼到一樓群組。她沒有解釋太多，只問一句：誰剛才收到 C 桌補看？

群組裡沉默了五秒。

清潔阿姨第一個回：我收到一句「擦 C 桌」。我沒擦。

司機回：我收到一句「準備輪椅」。我沒推。

夜班小館員回：我收到一句「第三頁已補」。我不在服務樓。

這三條回覆像三顆小釘，把一條看似完整的補看流程釘出破洞。原來 C 桌不是等一個人坐下才開始，它先叫人擦桌、推輪椅、補第三頁，再等家屬來把缺口補成人情。

不是抓到主使，而是普通人把「收到未做」同時說出來，讓流程無法再假裝所有半步都已經自然發生。

周祈把那些回覆抄到白板上，旁邊寫：半步不等於完成。

螢幕上的家庭照片又閃了一秒。這回遮罩晚了半拍，周祈看清孩子身後的牆。牆上貼著一張舊日曆，日期停在三月十七日，但桌上擺的生日蠟燭是十六根。

不是三一七。

這條線已經出現過，可每次出現都不讓他靠近完整答案。周祈喉嚨發乾。他想起父親周志遠拒絕開麥那晚，想起錄音帶倒帶，想起第一個孩子仍在 B 桌。這一切都像有人把他推到 C 桌旁，要他自己坐下補看。

林岫站到他身側，聲音壓得很低：「你不坐。」

「我知道。」

「知道也要說出來。」

周祈看了她一眼，忽然笑了一下，笑得很短：「我收到誘惑，未坐下。」

這句讓一樓幾個人都看向他。說出誘惑很丟臉，尤其對他這種一直把黑箱翻成人話的人。可他說出來後，C 桌椅子那七公分壓痕竟像鬆了一點。系統最怕的不是他完美冷靜，而是他把自己的不完美也變成現場證詞。

前台小姐把這句印出來，貼在桌牌旁。熱感紙一貼上，螢幕下方跳出新提醒：請勿張貼無關資訊。

林岫把這行拍下來，說：「它急了。」

一樓有人笑了一聲。笑聲很小，卻讓緊繃的空氣裂開一點。笑不是不怕，是大家突然發現那個客氣流程也會露出惱羞成怒。

服務樓沒有給他們太久喘息。消防梯裡傳來一聲輪子摩擦地面的聲音。老高要往前，被老太太拉住。老太太剛才差點自告奮勇，如今先把自己的熱心收回來，用菜袋擋住半步：「先問來處。」

這句從很多本事不大的人口中說出來，才算真的被用出去。

周祈讓老高不開門，只對著門縫問：「誰在裡面？」

裡面沒有回答。輪子聲又近一點，像有人把空輪椅推到門後。C 桌螢幕同時跳出倒數：02:00。

前台小姐臉色一白：「兩分鐘後會怎樣？」

周祈看著倒數，翻成白話：「它會說補看逾時，改由現場工作人員代確認。」

老高罵了很髒的一句。這一罵反而讓大家懂了：若兩分鐘內沒人坐，系統就要借保全、前台或清潔的手說已看。等於坐不坐都被它安排好。

林岫把手機對準倒數，對所有人說：「誰都不要代確認。收到提醒的人，把手機放桌上，螢幕朝上。」

一部、兩部、三部手機放上來。提醒不同，語氣都客氣。協助補看、避免阻塞、完成善後、照顧家屬。每一句都像好話，好到足以讓人做完才發現自己被借了。

周祈在白板上寫：好話也要問來處。

倒數到一分鐘時，消防梯門底下推出一只小紙袋。紙袋很舊，封口貼著服務樓的藍色標籤。標籤上寫 C-317，下面一行小字：家屬補看資料。

中年男人差點伸手。他是家屬，看見家屬兩字，本能地以為自己該拿。老太太一把抓住他的袖子，聲音粗起來：「你先問，是誰叫你拿！」

中年男人愣住，隨後眼眶紅了。他把手收回來，說：「我想拿，未拿。」

這句一出，倒數停了一秒。

周祈用文件夾把紙袋推到桌面光下，不碰封口。林岫拍標籤，前台小姐印時間，老高報位置。紙袋背面露出一截紅色原子筆筆帽。照片裡那孩子拿的也是紅筆。

周祈的手指緊了一下。他仍沒碰。父案越靠近，他越不能讓自己成為那只最順手的手。

倒數歸零。

螢幕黑了一瞬。所有手機同時震動，卻沒有新提醒。服務樓像卡住了，不知道該把誰寫成代確認。這一刻，一樓每個人都沒有贏得多漂亮，但他們共同守住了最要緊的一件事：沒有人坐下，沒有人代看，沒有人因為好心替流程補完。

小綠燈熄滅。

假鬆一口氣剛冒出來，紙袋裡的紅筆帽自己滾了一下。

林岫抬手，示意大家別動。周祈低頭看，發現筆帽滾出的角度正對 C 桌右側，那裡原本空著，現在桌面慢慢浮出一行壓痕。

不是電子字，是有人早就用硬筆在桌面背光處刻過。

周祈用手機側光照過去，字一個一個浮起：周志遠拒絕補看。

他整個人靜了一秒。父親不是沒來過 C 桌。父親來過，拒絕過，並且把拒絕刻在桌上。這不是完整答案，卻是一根能握住的釘。

林岫沒有安慰他，只問：「要不要讀出來？」

周祈喉嚨很緊，最後還是讀了。讀完後，他補了一句：「拒絕，不等於缺席。」

前台小姐把這句印出來時，手還在抖。印表機吐出熱感紙，紙邊卻多出一行不該有的灰字。


前台小姐把「拒絕，不等於缺席」貼上去後，服務樓一樓的人終於敢呼吸。呼吸聲很雜，和空調聲混在一起，像一間平常太安靜的服務大廳突然恢復了人味。周祈卻沒有離開 C 桌。他知道黑箱最愛等人鬆一口氣，再把剛才的勇敢整理成下一格資料。

老高蹲下看桌底，沒有伸手，只用手電照。桌底貼著一枚透明膠片，膠片邊緣有灰。灰不是今天的，至少貼了幾年。林岫拍下來，問前台小姐這張桌何時換過。前台小姐翻設備本，說 C 桌三年前從舊倉調上來，登記理由是家屬區增補。

三年前。周祈聽見這個時間，喉嚨又緊了一下。周志遠那晚拒絕補看，桌子後來被調到一樓，像某個沒吃完人的工具，被洗乾淨後繼續放在家屬面前。

中年男人低聲問：「那我們現在坐過的桌，也可能以前做過別的事？」

「可能。」周祈說，「所以先問桌從哪裡來，不問誰該坐。」

這句很快被前台小姐寫上白板。她以前最怕寫錯，如今字越寫越快，甚至主動在旁邊畫了三欄：桌號、來處、今日誰未坐。畫完後她自己愣了一下，像發現原來防線不一定要等周祈說完才存在。

清潔阿姨從群組回到現場，手裡還拿著拖把。她一進門就說：「我收到擦 C 桌，但我今天只擦到 B 桌右邊，因為那裡有膠。」她說完把拖把放下，拖把頭朝上，讓大家看見沒沾 C 桌酒精味。

這種小證很難看，卻很實。服務樓把清潔當作最容易借的手，現在這隻手先把自己沒做的事說出來。林岫把拖把頭拍下來，順手問她收到提醒後第一個念頭是什麼。

清潔阿姨臉一紅：「想快點擦完，免得被說不配合。」

她說完後，大廳裡好幾個人都低頭。大家都懂這種想法。沒有人真的想害人，只是不想被說不配合。黑箱最會把這句不配合變成鞭子，抽得普通人替它補完半步。

周祈把這句翻成白話：「怕被說不配合，不等於同意代確認。」

前台小姐印出來貼上。熱感紙一貼，C 桌螢幕黑屏邊緣冒出一條淡灰線，像系統正在改界面。它不說話，卻把剛才那句「請周祈本人補看父頁」往右挪了一點，右側多出一個小小的確認框。

確認框沒有按鈕字，只是一塊空白。

林岫冷聲說：「連字都不寫了，等人自己理解。」

老太太把菜袋放到椅子上，說：「空白也要問來處。」她剛才差點代看，現在反而成了盯空白最狠的人。她讓中年男人別靠近，自己也站遠，只用菜袋佔住椅面，不讓任何人的身體先坐下。

菜袋裡那只饅頭還熱，熱氣在塑膠袋上起霧。C 桌椅子被熱氣一熏，椅背底下浮出一道淡淡的膠痕。膠痕形狀像舊標籤，被撕掉很久，只剩邊框。老高一看就說，這種標籤不是服務樓現在用的，是舊倉設備封條。

舊倉又回來了。

周祈沒有讓這個詞把場面拉遠。他讓老高說封條平常貼在哪裡，清潔阿姨說撕封條會留下什麼膠，前台小姐查 C 桌移交單。三個普通流程拼在一起，比一句舊倉陰謀更能站住。

移交單很快找到了，單上有一格簽名被影印得太黑，看不清。前台小姐以前會說資料不清楚，今天卻把影印件和原始掃描檔都打開，讓大家看見黑的不是掃描，是原本就被重描過。

「這不是看不清。」她說，「是被描黑。」

前台小姐不是受驚的工具人，她開始能把行政語氣拆回具體手法。林岫對她點了一下頭，沒有誇，只把鏡頭對準那格簽名。被描黑的筆畫下方，透出半個周字。

周祈的手心濕了。

林岫立刻說：「半個字，不等於你爸簽。」

這句救了他一秒。半個周不能成為周志遠簽過，不能成為周祈該補看，更不能成為父子兩代都該被拉到 C 桌的理由。周祈把這句重複了一遍，聲音有點啞。

服務樓的系統像聽懂了他的猶豫，螢幕上確認框旁浮出一行新字：家屬可協助確認歷史頁。

客氣，正式，讓人難以拒絕。中年男人下意識看周祈，像想說我可以幫你。老太太立刻拍了他手背一下：「你自己剛才都差點被帶走，還幫人？」

大廳裡有人笑出聲。笑聲讓中年男人臉紅，卻也把那份好心攔住了。他自己說：「我想幫，未幫。」

前台小姐貼上這句。清潔阿姨跟著說：「我也想擦掉，未擦。」老高說：「我想開消防梯看，未開。」每個人都把想做和已做分開，系統那個確認框便一直空著，沒有抓到任何一隻順手的手。

假鬆一口氣又來了。C 桌不再閃，消防梯也安靜。周祈把目光落到桌面那行「周志遠拒絕補看」上，忽然看見拒絕兩字下方有細細的第二道刻痕。不是字，是一條箭頭，指向桌牌底座。

他沒有掀桌牌。先讓林岫拍箭頭，再讓老高用紙板把桌牌底座墊起一點。底座下壓著一小片熱感紙，已經褪色，只剩時間清楚：03:01。

三點零一。

父案線又靠近了，近得像一口冷氣吹到耳後。周祈差點伸手，林岫沒攔，只說：「說出來。」

周祈閉了閉眼：「我想拿，未拿。」

這句說出來時，他覺得丟臉。可丟臉把他從桌邊拉回來。老高用鑷子把熱感紙夾出，放到透明袋裡。紙背面有一句已經褪得很淡的話：拒絕後轉 C。

林岫拍完後，轉頭問前台小姐：「轉 C 是轉到 C 桌，還是轉給姓 C 的人？」

前台小姐沒有硬答。她查舊表，查到一欄「C 類家屬安撫」。這種分類聽起來像客服，實際上卻像把家屬分成可安撫、可拖延、可代確認。她把表投到大螢幕上，沒有遮掩，讓所有家屬都看見自己可能被分成一類。

大廳這次真的炸了一下。有人罵，有人哭，有人問自己是哪一類。林岫沒有讓場面散掉，直接喊：「先看自己的紙，不猜自己的類。」

這句把人拉回桌面。每個家屬拿出自己手上的單據，看欄位，看頁數，看有沒有 C 類字樣。普通人開始自查，黑箱就不能只靠後台分類吃人。

周祈在這片雜亂裡反而冷靜了一點。他看見系統試圖把憤怒引成亂，把亂寫成情緒阻塞，再借老高或前台小姐出手安撫。於是他讓老高站到門口，不安撫，只報位置；讓前台小姐只印紙，不勸人；讓林岫只問可驗問題，不追問隱私。

每個人只做一件可說清的事。

螢幕右側的確認框終於消失，取而代之的是一行更冷的提示：父頁暫緩，改送 C 類核對。

周祈笑了一聲，笑意很淡：「它換桌了。」

不是敗退，是換手。它失去周祈本人補看，便改送一群被分為 C 類的家屬去核對。更廣，也更髒。剛守住的一步之後，壓力反而擴開。

老太太忽然舉手，手裡拿著自己的掛號單。上面沒有 C，卻有一個小小的「旁聽」。她問旁聽算不算同意。這問題一出，所有人又靜下來。原來不只 C 類，旁聽、協助、見證、代收，每個好聽欄位都可能藏著一只手。

周祈把掛號單放到光下，仍不替她答。他讓老太太自己說：「我在場，不代聽。」老太太說完後，旁邊幾個人也跟著學。大廳裡形成一種參差不齊的回聲：在場，不代看；旁聽，不代認；收到，未執行。

這回聲比任何技術破解都慢，卻也更難被悄悄抹掉。

就在回聲裡，消防梯再次亮起燈。燈不是綠色，是白色，像醫院夜間走廊那種不近人情的白。梯門沒有開，門縫下卻滑出一張新的桌牌。

桌牌上寫著：C2。

林岫把鏡頭對準它，沒有靠近。周祈看見桌牌背後壓著一張舊照片的角，角上有紅色原子筆畫出的圈。圈住的不是孩子，是照片邊緣一個幾乎被裁掉的大人手。

那隻手戴著服務樓舊工牌。

周祈剛要看清，螢幕上跳出新的時間。

十一點十九。

只剩一分鐘。





周祈看見大廳裡每個人都在看自己的單據，忽然意識到這一輪真正卡住系統的，不是某個答案，而是每個人都開始不信「順手」。順手幫忙、順手確認、順手刷新、順手維持秩序，這些原本被包成好習慣的小動作，現在全被攤在燈下。

他把這句話縮成白板上的一句：順手前先報。林岫看了看，改得更狠：順手不是同意。前台小姐印出來，貼在 C 桌與消防梯之間，像在兩個口子中間釘了一根很土的釘。

十一點十分已到。
C 桌不再亮，消防梯裡亮起另一盞燈。
燈下的新提示寫著：十一點二十，請周祈本人補看父頁。
