晚上八點四十七分，服務樓一層的燈比白天更客氣。不是更亮，而是每一盞都像特意往人臉上鋪了一層不刺眼的白，讓排隊、等號、低聲問路這些事看起來比白日更體面，也更不值得起疑。周祈站在自動販賣機旁，一邊喝冷掉的黑咖啡，一邊盯著走廊盡頭那塊新換上的燈箱。白天三樓那張 teacher ready 小卡已經夠冷，夜裡這塊燈箱卻把那股冷包得更像服務：夜班導引支援，請跟隨熟悉人員。旁邊還有一行更小的英字，白得幾乎被燈吃掉，卻還是被他看見了：corridor hand set A active。

林岫比他晚兩分鐘到，手裡抱著一卷剛從影印店借來的白紙和一個塑膠喇叭。她一進門就先笑了一下，笑意很薄：「白天叫 teacher hand，晚上就變熟悉人員。這樓真懂怎麼讓人放下戒心。」周祈沒接她的冷笑，只把咖啡杯往垃圾桶邊一放：「A set 開了，B set 昨天下午剛露過頭。今夜不是臨時幫忙，是排班。」說完，他把一張從下午偷抄下來的便條遞給她。便條上只有三欄：window escort、family assist、corridor confirm。每欄後都打了空框，像有人正等著把哪幾個最像會幫忙的人填進去。

一層候位區比白日少人，卻更散。抱著毯子的老人、坐輪椅的婦人、帶著發燒孩子的父親、下班後來補蓋章的夜校學生，都各自縮在塑膠椅裡，像一點點小光落在更大的一團白裡。最顯眼的是窗口邊那三個人。白天在二樓幫忙念字的前台小姑娘，換了夜班背心；下午在三樓拿著白板錄音的清潔阿姨，這會兒被請到走廊口遞號碼；還有那個淺灰背心的行政男生，正低頭在平板上勾一串名單。三個人都不是壞人，甚至比樓裡大多數人更像「肯多幫一下」。可正因如此，他們才最像夜班影手會先去挑的人。

九點整，服務樓的夜號燈一跳，整條走廊像被無形地分了流。原本該在一層等叫號的人，被窗口小姐輕聲請到側邊；原本只要補一張家屬章的老人，被說成「夜間流程改在走廊確認更快」；連一個抱孩子的父親都被勸去邊上那條灰白地墊鋪出的窄道，理由還是那句最客氣的話：我帶你，省得多走。周祈站遠遠地看，不必追平板，也知道那三欄空框正在被一格格填上。不是誰拿槍逼誰，是燈、口氣、夜班疲勞和「快一點」一起把人慢慢往熟悉人員手上送。

林岫沒先衝上去拆，而是把白紙一張張鋪到候位區那塊公告板上，最上頭只寫大字：只幫念，不幫點。旁邊再補：跟你走的人，也會被記。她寫得又快又粗，像怕這句話若不夠土，夜裡的人看一眼就會滑過去。前台小姑娘一抬頭看見這行字，手裡那支感壓筆明顯停了半秒。她其實已學會不替別人畫圈，可夜班這套更深，根本不需要她碰筆，只需要她走在前面，替人帶到該站的位置。這種「只帶路」比白欄更毒，因為人人看起來都還像自己在做決定。

真正的第一個撞口，是那個帶著燒孩子的父親。他白天也來過，已在二樓學會「慢一點也算本人」，可夜裡人一累，警覺會先塌半層。清潔阿姨柔聲叫他往走廊深處去，說那邊有熟手能幫忙先過。孩子正燙得發紅，他一聽「先過」就動了。周祈在這種時候向來不愛說大道理，他只走到那父親旁邊，指著公告板那句「跟你走的人，也會被記」，用最白的話說：「她帶你走一次，明晚她就會被樓上當成熟手。你若孩子明天還燒，你還是得再找她。找到最後，不是你在走流程，是流程在養她。」這句話一落，那父親臉色先是一愣，再看向清潔阿姨手裡那張小小的夜班卡，像終於意識到自己以為被照顧，其實也在替別人鋪班。

可夜班真正難拆的，還不是有人主動來帶你，而是你自己在最累的時候也會想找那張熟臉。下一個起身的是一位推輪椅來補藥章的阿嬤。她白天就來過，記不住窗號，也看不清箭頭，一見前台小姑娘便本能喊：「妹妹，你再帶我一趟，我腳慢。」這一聲喊得極自然，連周祈都差點找不到切口。因為阿嬤沒有被逼，也不是被哄，她只是單純在求一口自己記得住的好心。樓上最愛吃的，正是這種真心。林岫沒直接攔，只把一張新的白紙貼到輪椅前，寫得像跟老人家講人話：她若總帶你，明天她也走不掉。阿嬤怔了怔，抬頭看那前台小姑娘。小姑娘嘴角一緊，卻硬是把想往前的腳收住了，改蹲下來指地上的藍箭頭：「阿嬤，我陪你看牌，不推你走。」這一改很小，卻把「熟人帶路」硬生生拆成了「本人看路」。輪椅走慢了，卻沒有再把一雙手一起交出去。

保全大叔原本還覺得這些話太矯情，等他看見阿嬤自己推著輪子，一格一格對箭頭，竟真走到該去的窗口，臉上的不耐便淡了半寸。周祈抓住這口鬆動，把下午從三樓摸到的另一句殘字補上白紙：escort path stable if repeat face。下面直接翻成白話：同一張臉帶你兩次，路就熟了。夜裡的人未必懂英字，卻都懂「同一張臉」。懂到有幾個原本要排去走廊確認的人，竟自己把號碼單折起來塞回口袋，寧可再等半小時，也不肯讓那張熟臉一路帶到底。

這一層一鬆，樓上也被逼急了。走廊口那扇平日只在清潔時才開的小側門忽然被推開，一名戴藍夾名牌的年輕女職員走出來，笑得比誰都柔，說辭卻更圓：「各位別誤會，熟悉人員不是代理，只是陪伴。像老人家、孩子、第一次來的人，有人陪著總比較不慌。」這種話若在白天說，可能真能把很多人安撫住。可今夜公告板、白紙和夜班卡全擺在這裡，她越溫柔，反倒越像在替某套更深的流程抹粉。林岫索性把喇叭往她嘴邊一遞：「那你敢不敢現在就說，陪伴的人不會被排進下一班？」女職員笑意卡了一瞬，只剩一句「這要看現場需求」。周祈立刻在白紙上補：看現場需求＝看誰最好用。這句又粗又狠，卻把那層最會哄人的客氣皮一下扯開。

清潔阿姨被看得眼圈發熱，低聲罵了句「這都什麼鬼差」，乾脆把那張卡翻給他看。卡面正中印著 support contact，背面卻壓著一條更細的灰字：escort preferred if family agitation high。林岫眼疾手快，把那句抄上白紙貼到公告板旁，再用喇叭大聲念了一遍。夜裡的候位區本來最怕吵，這一嗓子下去，所有人都抬了頭。有人不懂英字，卻聽懂了「家屬一亂，就優先找熟人帶」。這比白天那些 proxy、teacher 還直。因為它把「你現在很亂，我來幫你」直接寫成了排班理由。

淺灰背心行政男生立刻從平板後頭站起來，笑得很客氣：「各位不要誤會，這只是夜班支援，主要怕老人、小孩走錯……」他話沒說完，林岫已把喇叭一轉，對著全廳白話翻譯：「意思就是誰看起來最像會乖乖陪你走，誰就先被挑去帶。帶久了，以後你一亂，他還得再來。」夜裡的人不愛聽術語，卻很會聽這種話。輪椅上的婦人先把孫女拉回自己身邊；夜校學生把剛站起來的屁股又坐回椅子；連最怕麻煩人的老人都開始問：那我自己慢慢走，算不算。周祈便趁勢把第二張白紙補上去：自己走，走慢也算。沒看路，不算確認。

走廊另一頭的燈忽然一暗一亮，像有人在樓上切了模式。周祈順著光看去，果然見到灰白地墊盡頭多出一塊更小的告示牌：corridor hand set B standby。B 還在待命，A 已經啟動。這代表有人在夜班裡把「誰帶老人、誰帶家屬、誰帶不會點的人」拆成兩組手。A 組先碰亂的人，B 組補沒那麼亂、卻更容易被說服的人。他想起父親舊電腦裡那串 0311_precheck_local，只覺得背脊又冷半寸。這樓不是單純預測哪裡會出事，它在排誰該站上去，讓事情看起來像自然發生。

九點二十，前台小姑娘終於頂不住了。她把手裡那支筆拍到桌上，聲音不大，卻清清楚楚：「我今晚只報號，不帶人。」這話比任何程式碼都管用。因為她白天已被養過一輪，若連她都在夜班把手收回來，整條樓的節奏便會先卡一下。保全大叔原本還想勸她「就帶一個老人過去」，被她一句堵回去：「我帶一個，明天就成我的活。」保全大叔怔了怔，竟也沒再往前。他嘴上總愛說快一點，可誰都知道，真被樓上盯成熟手的若是他，以後每逢家屬鬧、老人慢、孩子哭，第一個被推出來陪走廊的就是他。

這些普通人的一點點猶豫，反而把黑箱逼急了。行政男生手上的平板亮度忽然往上跳，螢幕角落彈出一條新的提示，只有兩秒，卻還是被周祈看見：night queue pressure high / lead assist assign。不是讓人幫忙，是直接分派。周祈沒去搶平板，只把這七個字轉成人話寫到白紙上：你一急，它就幫你安排誰來帶。夜校學生一看這句話，臉色都變了。他本來還想著「有人帶比較不會走錯」，這下卻忽然意識到，自己的不熟、急躁和夜班疲勞，本身就是被樓上當成可預測的入口。他把剛領到的號碼紙塞回口袋，改問：「那我排久一點呢？」林岫拿喇叭回他：「排久一點還是你。被帶走一次，下一次可能就不是。」

真正把夜班影手拆白的，是一張排班紙。不是誰偷出來的，而是清潔阿姨在擦走廊鏡面時，從告示牌背後摸下來的。紙不大，像臨時便條，列著 A1、A2、B1、B2 四個欄，旁邊不是姓名，而是特徵：夜班窗口熟、會安長者、家屬不反感、可白話引導。最末還有一行更冷的備註：優先沿用白日已學者。白日已學者。也就是說，今天二樓白欄前幫忙念字的人、三樓訓練端被教過慢畫的人、在走廊替別人解釋過公告的人，到了夜裡都會被當成可以直接沿用的手。這比任何產品設計都更像吃人，因為它吃的是白天那些看起來無害的善意。

排班紙一露，前台小姑娘整個人都像被人從背後潑了盆冷水。她盯著 A2 那欄「會安長者」看了很久，才小聲道：「昨天晚班我只是順手扶一個婆婆去洗手間。」那一扶連她自己都沒當回事，樓上卻記下來了。誰扶過、誰說話不嚇人、誰肯蹲下來陪老人慢慢看號，這些本該只屬於人的細節，一旦被抄進欄位，就會變成可排班的資產。周祈沒有安慰她，只把那欄白話寫大：你昨天順手，今天就變班。小姑娘看著那行字，肩膀微微發抖，卻終於自己把夜班背心脫了下來，掛在公告板角上。這動作比任何口號都有力。因為她不是在吵，只是在把那層最容易被沿用的身份先卸掉。

淺灰背心行政男生見局面滑走，第一次露出真急。他低頭在平板上飛快滑了幾下，像想把 A 組改成 B 組，或臨時抽掉幾個標記。可越急，越露底。周祈站到他側後，看見平板一閃而過另一行灰字：promote from escort if calm success >=2。當場沒去搶，只直接對周圍的人翻成人話：「同一個人如果陪兩次沒出事，就升一格。今夜帶路，明夜就能帶更多。」保全大叔聽到這句，整張臉都黑了。他最怕的不是幫一次忙，而是幫著幫著，再也退不下來。於是他乾脆把自己的值班筆記本翻開，當眾寫下：本班只報事，不陪走。又把那頁夾在胸前。字醜得要命，卻讓更多夜班人第一次敢把「不做」掛在自己身上。

這一掛，原本只在看的人也開始動了。夜校學生把自己剛印好的補件單背面翻過來，照著白紙抄了一行：我會念，不會帶。戴眼鏡的女生則去借了前台印章盒，直接在號碼紙背後蓋上三個字：本人到。她蓋得很重，像怕夜裡的白燈一照，人的在場又被誰客氣地擦薄。周祈看著這些又笨又土的反制，忽然覺得父親當年若真死在這套流程裡，最可怕的恐怕也不是什麼高深模型，而是沒有人在白天把這些笨法先做出來。只要沒有這些白話防線，夜班每一句「我幫你」「我帶你」都會自然得像天經地義。

走廊盡頭那塊灰白地墊在這時又亮了一下，不是燈變，而是有人從裡面把第二張更小的卡放到了牌子旁邊。林岫隔著半條走廊用手機拉近，屏幕上只有兩行淡字：shadow shift starts after trust formed。她看完，直接笑出了聲，笑意卻一點不暖：「連『信任形成後』都寫進去，真是怕自己學不夠。」周祈把這句翻成白話貼出去：你信它兩次，它就開始排班。這一下連最慢的輪椅阿嬤都看懂了。她抬頭瞪著那塊小卡，忽然用力拍了拍輪椅扶手，嘟囔一句：「我信我自己慢。」這句像孩子話，卻把整個候位區都逗醒了半寸。有人笑，有人罵，有人跟著重複「我信我自己慢」。夜班最怕的就是這種自己把話權搶回去的低聲雜響。它不大，卻能讓那套最會包裝成服務的影手語言再也裝不乾淨。

這一點亂聲，反而比整排英文都更像活人。

林岫把排班紙拍照、放大、再用喇叭一條條念。這回候位區不只安靜，而是帶了點壓抑的火。輪椅婦人的孫女先把清潔阿姨拉去自己旁邊坐，說阿姨你別帶我阿嬤，我陪她慢慢走。夜校學生主動接過公告白紙，幫忙一張張貼到走廊口，嘴裡還嘟囔「誰都別當你們的 A2」。帶燒孩子的父親乾脆搬了兩張塑膠椅堵在灰白地墊前，說要走的人自己看完牌再走。這些動作都不英雄，也不乾淨，卻把那條最像服務的夜班熟手路，一寸寸拖回公共場面。周祈站在中間，第一次覺得這棟樓的恐怖不是多高深，而是太懂人會在哪裡累、在哪裡想被幫一下。

九點四十六分，三樓那點藍光終於滅了半盞。沒全滅，卻像有人在樓上發現，A 組手不夠順，B 組也接不上。行政男生試著把平板收回懷裡，表情還維持著客氣，手指卻已經有點抖。周祈走到他面前，沒搶，只問一句：「誰在排這個 lead assist？」男生咽了口唾沫，第一反應仍是公事公辦：「只是夜班支援，避免家屬焦躁……」周祈便直接指著排班紙最末那句「白日已學者」，一字一頓道：「這不是支援，是沿用。你們不是怕人走錯，是怕今天沒把白天養熟的手接著用掉。」男生嘴角顫了顫，終於沒再說完整句子，只低低冒出四個字：「上面排的。」

這四個字不夠，但也夠了。因為它證明夜班影手不是現場小聰明，而是更高處的固定習慣。候位區裡有人開始小聲重複「上面排的」，像把一個抽象黑箱第一次壓成真能往上指的白話。林岫趁熱把最後一張紙貼上去：上面排的，也得在下面露手。她貼得歪，膠帶還多翹一角，卻偏偏比一整面乾淨告示都刺眼。因為夜裡的人最懂，凡是要你安靜配合的地方，最怕的就是下面忽然有人把它講成人話。

夜班沒有就此停擺。老人還是慢慢走，孩子還是會哭，窗口還是得叫號。可那種「跟著熟悉人員就好」的滑順感，到底被這一晚的白紙、喇叭、塑膠椅和幾個普通人的猶豫卡斷了。前台小姑娘真的只報號不帶人；清潔阿姨改去教老人看箭頭，不碰腕；保全大叔嘴裡雖還念著「麻煩」，卻硬把自己站成一塊看牌告示，不再走在前頭。黑箱最想養的，就是這些最像服務的人。可今夜他們一個個把自己的手從那條路上收回來，樓上那套排班便只能亮著燈，暫時學不完整。

周祈收白紙時，從排班紙背面摸到一行更細的舊字，像被誰匆匆劃過又用指腹抹淡：0311 night escort learned。父案的時間碼不是幻覺。這條路，早在那年夜裡就開始學了。只是今天，它第一次在普通人眼前露得這麼白。周祈把那行字記進心裡，卻沒當場說。因為他知道，下一步要追的，不是證明這幾個英字可怕，而是找到誰在上頭把人一批批排進「可白話引導、家屬不反感」這種看似無害的格子裡。

林岫把喇叭關掉時，樓裡只剩空調和遠處叫號聲。她看著那幾張歪斜的白紙，低聲道：「夜班比白天冷。因為它把體貼包得更像體貼。」周祈點頭，目光落向走廊盡頭那塊還沒拆掉的灰白地墊。上面鞋印很亂，不再像一開始那樣直。他忽然覺得，這也算一種局部勝利。只要腳印還亂，影手就沒法把每個人走成同一條線。

而今夜最值得守住的，不是誰沒被帶走一次，而是很多人第一次知道：你若總替別人圖快，樓上就會順著那份快，把你養成下一班該出現的人。
