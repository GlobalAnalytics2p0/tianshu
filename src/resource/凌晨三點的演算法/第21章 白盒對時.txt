兩點十四分過後，閱覽三室裡那股塑膜和舊紙混在一起的焦氣，反倒比剛才更淡了，這通常不是好事。

焦氣淡，說明火沒停，只是被人收得更薄；紙還在，卻被放到了最不容易叫旁人聞出來的地方。周祈半蹲在三室最裡那排低櫃後頭，手裡捏著那張列了`lamp on / table clear / sync queue / witness removed`的對照欄，背上一層冷汗遲遲沒退。剛才他們逼出女清潔工、時間貼條、`conf-split B`，看似已把三室這一口拉到白天眼前，可他心裡反而更沉。因為越看到這裡，他越知道三點那一下不是起點，而是很多普通人各做半步後，最後一起把結果「交回去」的終點，這種流程，最難斷。

斷一個人沒用，斷一張單沒用，斷一只平頁套也沒用。要讓它今晚真咬不下去，只能把它每一口看似再正常不過的準備動作，全拖到很多人都能看見的地方，所以他先沒追那只滑進書櫃更裡的深色片匣。

林岫一開始還想再往窄縫裡拍，周祈卻先搖頭。片匣若真還能往裡滑，說明三室之後另有口。此時撲進去，只會逼得更裡那手把東西再送深一層，還能回頭說前台、清潔和閱覽室只是夜裡例行整理。比片匣更值錢的，是那張白盒子前的時間線，是誰在兩點一刻前看表，是誰在燈亮前先把桌子清空，是誰覺得見證人多留一個都算「異常」。

前台小姐站在三室外的走廊口，臉還白，抱著那塊灰底掛停表的手卻沒鬆。她平日做事細，一到晚上更怕麻煩。若放在兩個月前，周祈根本想不到她會替自己擋著一整條夜班走道。可人一旦知道自己平日守著的不是普通外皮，而是別人凌晨三點要拿去套命的皮，再怕事的人也會生出另一股硬。

「現在怎麼辦？」她問。周祈把那排掉出來的時間貼條在她面前一字排開，02:14
02:27
02:41

三個時間，不長，也不複雜。卻像三個在城市夜班裡再普通不過的小節點：清潔工繞一趟、館員回一次架、前台交接一個內線、保全喝完半杯茶。誰都不會把這些動作當成殺人流程的一部分。

「它不是等三點才開始。」周祈說，「是把三點以前每一件該順的事都先順好。燈得亮，桌得清，東西得對，見證人得少，最後三點只負責把早就對好的結果吃進去。」前台小姐沉默了兩息，突然問：「那我們就一直把見證人留著？」

「不只留著。」林岫替周祈答了，「還要讓它知道，留著的人會記，會問，會對時間。」

這句話一落，走廊裡幾個原本只想先把今晚撐過去的人，眼神都變了變。高哥從門邊抬起頭，小館員把抱著的索引冊抱得更緊，清潔阿伯則下意識回頭看了一眼最裡那盞小白燈。這些人未必懂什麼叫`split`，卻都聽得懂「對時間」。夜班最容易糊掉的就是時間，什麼時候拖地、什麼時候回架、什麼時候巡一趟、什麼時候打卡補簽。若有人拿這些誰都懶得對的時點，拼成一條凌晨三點的白路，那麼反咬它最笨也最準的法子，便是反過來讓每一口時間都有人記，周祈立刻把工重新分了。

小館員不再只記經過誰，她要把每一個人靠近三室的時間寫死，寫到分鐘。前台小姐守走廊口，誰來都要當面問「幾點來、做什麼、哪個主管叫的」。高哥不再只堵人，他去盯最裡那只白盒子外接的總線，誰碰燈誰碰櫃誰摸書架都要報。林岫則直接把三個時間貼條拍進手機，又用筆在紙上劃一條簡單得連清潔阿伯都看得懂的時間軸：兩點十四預對齊、兩點二十七看表、兩點四十一移除見證、三點同步。

「對不上就說出來。」她看著眾人，「不要怕顯得自己笨。越多人問，這套流程越不像正常。」這才是黑箱最怕的。不是有人比它更懂，而是很多原本不懂的人一起開口，把它的順手活變成公共場面。兩點二十一分，第一個不該出現的「正常」又來了。

這回不是女清潔工，而是閱覽部夜班副館員周姐。她平日脾氣好，說話總像替人省事，最愛的口頭禪便是「這格我來處理，你們先去忙別的」。前台小姐一看見她，神色就緊了緊。因為三室這條走廊若真要有人來收場，最像「正常」的人，正該是這種資歷久、說話穩、誰都習慣讓她接手半步的人。

周姐一進來先笑，笑得像真只是夜裡多走一趟：「三室還沒回暗？總館那邊剛問了，說晚班若超時，明早館配會對不上。」太合理，合理得連高哥都差點想讓，周祈卻立刻聽出不對。

館配會不會對不上，這本該是三點後才有人在意的事。周姐一進門卻先提，說明她來之前就知道今晚這條路和館配有關，更知道三室不是單純停架，而是某種會影響後續「對上」的前置口。

前台小姐照周祈剛交代的，一字一字往外問：「現在幾點？誰叫妳來？要處理哪一格？」

周姐笑意淡了一下，卻沒立刻散，反而把手機翻過來，讓螢幕亮在眾人眼前。畫面是一則再普通不過的館內群訊：

`R3 check if light on. If yes, table clear first.`沒有署名，沒有工號，沒有主管名，只像某個夜裡順手提醒的群組訊息，這種東西最髒。

因為它不命令，只提醒；不對具體物件下手，只說「若燈亮，先清桌」。誰真照做了，事後也能說自己只是好心把事情做順。林岫看了一眼便笑了，笑意冷：「可我們剛好就在記誰把桌子清成那樣順。」周姐第一次真沉了臉。

她顯然沒料到今晚這條走廊不只有人守著，還真把「時間」和「誰先清桌」這種平時最沒人願意對的東西記了下來。她想說這只是夜班互相提醒，周祈卻已往前一步，先把那張`witness removed`的對照欄攤到她面前。

「那這個呢？」他問。周姐看見那一欄時，眼神不是陌生，而是本能地先往林岫相機那頭飄了一下。這一下，比任何辯解都真。她不認得這張表也沒關係，她至少一眼就知道，這東西不該被拍進白天人能看懂的畫面裡。

高哥看懂了，往門框上一靠，語氣反倒比誰都平：「桌子誰清的，燈誰亮的，見證人誰想挪開的，今晚慢慢對。」周姐沒再多說，只道自己先去拿鑰匙，便想退。

周祈卻沒攔她，只看著她走到走廊轉角，掏手機發了一條更短的訊息。背影不慌，步子卻快了半拍。這種人最難追。她未必是核心，未必碰過片匣，也未必知道三點同步後到底發生什麼。可她一定知道哪個時間點該叫誰來，哪張桌應該先清，哪盞燈如果沒亮，就得有人先去摸最裡那只白盒子，她也是半步工，而半步工越多，黑箱越穩，兩點二十七分到了，白盒子果然有動靜。

不是響，也不是亮，而是那盞最裡的小白燈忽然極輕地閃了一下，像有人在另一頭按了一次短測。清潔阿伯就在總開關旁，立刻高聲說自己沒動。高哥已趴到低櫃邊去摸，三室裡別的電器全沒變，只那只白盒子後頭多了一點極細的震，周祈頭皮一麻，不是單純照明盒。

它更像一只本地脈衝口。兩點二十七這一閃，不是為了讓人看見桌亮了，而是要確認「預對齊這一步是否還在軌上」。

他立刻想到父親舊工作機裡那些零碎到讓他當年嫌煩的本地時間片。02:14、02:27、02:41，不是誰夜裡瞎記的打卡，而是每一層拆工口自己回報「我這半步做完了」的節點，系統不必知道誰做，它只要知道這一格完成了。

周祈心裡那股噁心感一下更重。這和他從前最熟的產品邏輯太像了。把大流程拆成一連串可觀測、可回報的小節點，做的人不必知道全局，上游卻能準確知道哪一格還沒準備好。只不過有人把這套本該拿來優化配送和推薦的東西，拿去優化了「怎樣讓一個人被送進三點後還像正常」。

「把白盒子拔了？」高哥低聲問。

「不能現在拔。」周祈壓住聲音，「它若是split A，現在斷，只會讓更外面那口知道這裡出事，立刻改路。」林岫看他一眼，立刻明白：「那就讓它回不到『完成』。」對，不拔，不停，不讓它直接報錯。

而是讓它一直卡在「有人、桌不乾淨、見證未移除、對時失敗」這種最難被當場說清、卻又最沒法照常往下送的狀態裡。

前台小姐一聽，反倒先動了。她把灰底掛停表直接從走廊口挪進三室門內，掛在最裡那張對齊桌邊。這一下很土，卻非常對。因為灰底掛停表一掛，桌子便不再可能被當成空桌；任何人想再說「table clear」，都得先把這塊牌從眾目睽睽下拿走。

小館員也反應過來，把那疊本該明早回架的索引冊直接放到桌上，還故意只放一半，讓桌面既亂又明白地「有人還在處理」。清潔阿伯更絕，從外頭拖來一只真裝著半桶髒水的拖把桶，往三室門邊一擱，嘴裡還念叨著地未乾。這樣一來，誰若再硬要說見證人該退、桌面該清，便得先當著所有人的面，把一本本冊子、一塊掛停表和一桶髒水都搬走，普通人的阻力，就這樣一點點長了出來。兩點三十一，最裡那張空著的閱覽桌旁，果然又出現了另一個人，不是清潔，不是館員，也不是管理員。

是個穿最普通毛背心的中年男人，抱著一本書，像真有什麼資料忘了查，深夜回來補看。若不是小館員先說過「總有一個沒借閱紀錄的人先坐那桌」，誰都會被他混過去。可周祈如今再看這種人，第一眼先看的不是臉，而是手。

他右手沒戴手套，食指側邊卻有長年按紙、撥頁、看表才會有的薄繭。左腕很鬆，像不提重物，只習慣偶爾抬起看時間。這種人不搬箱、不推車、不補簽，只負責看一件事：兩點這一口，有沒有準時完成，看表手。林岫幾乎在同一秒也認了出來，鏡頭立刻抬起，男人卻沒往三室裡看，先看最裡那張桌，這一看，他整個人便僵了半寸。

掛停表、索引冊、拖把桶，還有前台小姐明晃晃站在桌邊。對他這種只負責確認「table clear」的人來說，眼前這一幕不是亂，而是失敗。不是核心件不見，而是最前面那格最容易被誰都忽略的準備口，第一次在白天人聲裡整個對不上，他沒立刻退，反而下意識去摸左腕，不是看錶，是摸錶後那只白塑料套。

周祈心裡猛地一跳。他不是普通看時間的人，他手腕上那只看似最廉價的白塑料電子錶，多半就是另一口本地對時設備。白盒子在三室裡發短測，他在外頭看手錶比對，二者只要一對上，便算這半步完成，這才是真正的split A。不在房間裡，不在高權限裡，就戴在一隻再普通不過的夜班手腕上。

周祈沒給他退的機會，直接從低櫃後走出來，一句話都沒先說，先看了眼林岫。林岫懂他，鏡頭立刻對準男人左腕。閃光一亮，白塑料錶面被照得清清楚楚。沒有品牌，沒有日期，只最上方極小一行灰字：

`02:27 align check`男人這才真慌，他第一反應不是捂臉，而是捂錶。這一下，便把所有還想裝普通夜讀的皮都撕了。

前台小姐倒吸一口氣，第一個罵出口的竟不是周祈，而是她：「你們連看幾點都能拿來接這種東西？」

男人想退，走廊那頭卻已被高哥和清潔阿伯堵住。拖把桶就擋在他腳邊，前頭又是掛停表與桌上的索引冊。他若硬撞，只會把整條時間線撞得更響。這對平時最怕聲、最怕見證的白路來說，比被人抓住更糟。他終於開口，卻仍是最普通的藉口：「我只是看館裡還有沒有燈沒關。」

「你看的是對時。」周祈盯著那只白錶，「不是燈。」男人眼裡那點否認只撐了一瞬，便碎了，因為周祈說對了。

對時手、亮燈手、清桌手、回架手、移見證手，誰都只做半步，誰都能替自己找出一百種「我只是夜班順手」的理由。可這種理由一旦被很多人一起聽見、一起對上時間、一起看見他手腕上那行`align check`，便不再是無辜，而是工序，而工序，是能被停的，男人還想撐最後那層皮。

「看燈、對表，本來就是夜班的事。」他喉頭動了動，像在找一句最不會惹人反感的話，「館裡不先把時間對齊，明早開館誰都要亂。」

這句話若放在一個月前，前台小姐多半自己都會點頭。館裡每晚都有這種「先對一對」的小事：前台的掛鐘慢了兩分、保全打卡機快了一分、清潔車記錄條沒對上、館配的車晚進十分鐘。只要不出大事，誰都寧可用一句「先對一對」把日子補平。也正因如此，確認鏈才會長到今天這樣，連對時都能借成工。周祈看著那只白塑料錶，忽然覺得喉嚨發緊。

他曾經也最信這一套。產品線、資料流、配送節點、推薦刷新，哪一個不是靠很多人默默把時間對齊，流程才顯得穩。從前他只覺得這叫專業，如今看著閱覽三室這群人，才第一次真正知道，當「對齊」落到人命上，最冷的從來不是一個大判斷，而是無數個小時間點都有人替它把事做順。

林岫顯然也想到同一層。她沒跟男人爭辯什麼系統與人，只把相機從他腕上移到他腳邊。那裡有一小片被鞋底帶進來的灰膜，灰不厚，卻偏偏只落在最裡那張桌與白盒子之間，像有人每回只走這一條來回口。

「你不是第一次來看這只錶。」她說，男人沉了臉。林岫繼續往下說，像在替所有人把這件事講成人話：「你們這些人最省力的地方，不是誰權限最高，而是每個人都只負責一小塊：有人把桌子清了，有人把燈試亮，有人把車推到位，有人只來看一眼時間。你們都覺得自己只是夜班裡最普通的一隻手，事情真出了，也能說自己沒碰內容。」

高哥原本只覺得噁心，這時卻真被說中了。他這幾夜守下來，最怕的也是這一點。因為越往裡看，越發現這不是一兩個壞人，而是一整條把「我只是照流程」說成習慣的路。清潔阿伯在旁邊嘆了口氣，聲音發澀：「難怪最髒的總不是動手那個，是老說自己只是補一步的。」

前台小姐聽完，像忽然把很多年來自己說過的話都想了回來。她抱著掛停表，盯著男人的白塑料錶，忽地問：「所以你每晚來看三室，不是怕燈沒關。是怕這裡沒在你們該看的時間亮、該空的時候空、該沒人的時候沒人，是不是？」男人沒有答，可他手腕那只錶的灰字忽然又閃了一下，從`align check`跳成了極短的一個詞：

`pending`只一瞬，可夠林岫再拍一張，也夠周祈心裡那條線再往裡咬一寸。這不是普通電子錶。它不是顯示時間，而是在接一個本地狀態。對時手之所以要站在這裡，不只是看表，而是等著看三室這格預對齊有沒有卡在`pending`。只要卡住，便代表後頭那口還得有人來「幫忙」。這樣一來，兩點四十一那口「移除見證」更不能放過。

因為對方既已看到`pending`，下一步便不會再只來看時間，還會來把讓它pending的東西一樣樣搬走。

前台小姐也在這時真正回過味來。她沒再只守著走廊口，而是直接把櫃台那台老舊熱感列印機拖來三室門外，當著所有人的面按下內線試印。機器吱地吐出一條白紙，上頭先是時間，後是她自己手寫補上的一句：`02:27 三室未清 / 見證在場`，這張紙毫不起眼，卻讓周祈心裡一震。

黑箱最會做的，不就是把很多現場變成沒人留下紙的空白嗎？如今前台小姐反過來，在最普通的館務列印條上把時間寫死，這便等於替三室搶下一張自己的「白天對照欄」。往後誰再想說兩點二十七一切正常，先得把這條紙也吃掉。

周姐站在轉角看見這一幕，臉色終於真變了。她本來只想把桌面和時間重新推回順手，如今前台、清潔、館員竟自己開始留時點、留紙條、留人證。這對她這種最習慣替流程抹平的人來說，比被人指著罵還難受，因為代表今晚的事已不是誰能私下補一句「內部處理」就能帶過。

小館員這時忽然又想起一事，急聲道：「兩點四十一前，還會有人來拿最裡那張讀者座牌！每次他一拿，三室就更像沒人了！」兩點四十一，最後一格，周祈低頭看手錶，時間正往那一刻壓去，他終於知道下一步該怎麼做了。

不是去追片匣，不是先拆白盒子，也不是逼這個看表手吐全套流程。今夜真正值錢的，是把兩點四十一那一下「移除見證」也當場拽出來。只要這格也在白天人眼前失敗，三點同步便再沒法像以前那樣裝成只是夜裡順手。他抬頭看向最裡那張桌，聲音很平，卻比剛才更硬。

「都別走。」他說，「還有最後一口人要來清場。」白塑料錶上的灰字仍在閃，而時間，正一分一分逼向兩點四十一。
