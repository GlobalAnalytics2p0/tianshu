天亮之後，前台這口燈忽然比夜裡更難看。不是因為光刺，是真把太多原本只該躲在側門、後台、地下一樓和「稍後為您處理」裡的東西，一股腦照成了桌面上的白紙。老太太那張「家屬在場單」被夾在透明板上，藍書包男人那張副聯塞在書包側袋，桌角還貼著前台小姐連夜手改的欄位：「入前台頁數 / 離前台頁數」。這些字既醜又土，卻像一排新釘，硬生生把整條最愛吃空白的流程釘在亮處。

周祈沒先補覺，也沒先回公司開什麼權限會。他靠在前台旁那口最笨的白燈下，拿紅筆把昨夜所有退回、回整、在場、轉交的時間重新抄成一條線。抄到五點四十七分時，他停住了，不是因為累。是因為那個時間之後，所有從桌面經過的人都變得太熱心。

幫老太太換筆的人、說要帶藍書包男人去旁邊坐的人、主動來點頁數的人，說話都很客氣，動作卻有一個共通處：手會先壓在頁子左上角，像怕風翻，實際卻正好蓋住最容易被順走的那一張關係頁，這種手勢太白天了。

白天到你若不盯著看，只會覺得對方是在幫忙整理。可周祈今夜一路從 split、handoff、family set、front return 走下來，已比誰都懂這條黑箱最狠的地方從來不是顯眼，而是順手。只要順手夠像正常人，少半頁紙、少一張關係欄、少一個等的人，隔半日便都能說成是家屬自己沒帶齊。他於是把紅筆一丟，對前台小姐說：「再加一欄。」

「什麼？」

「經手人。」前台小姐愣了一下，隨即懂了。她乾脆重新撕一張熱感條，直接把透明板上的欄位補成五格：「進場頁數」、「離場頁數」、「經手人」、「前燈狀態」、「是否曾被提議後側處理」。字還是醜，可一補完，整張表便突然有了牙。清潔阿姨蹲在旁邊看了半天，抬頭就罵：「你們這不是登記，是抓手。」

「本來就該抓手。」林岫說。她昨夜到現在沒離開前台多遠，手機電快見底，索性跟高哥借了充電線，插在最亮那口燈下，一邊充一邊拍。她比誰都清楚，這一局若要再往前卡，不靠地下設備，不靠高權限，而要靠這些最普通的前台動作被很多人一起看懂。黑箱會怕鏡頭，卻更怕鏡頭把它拍得像日常。六點一刻，第一個露出頁數差的人不是館配女人。

是個戴薄框眼鏡的行政男職員，姓葉，胸前掛著臨時服務牌，笑起來很斯文，一來便先幫前台小姐把散開的號牌盒排整齊。他說自己早班支援，昨夜值台的人辛苦，今天願意幫家屬做「前置整理」，免得窗口一開大家久等。這種人平日最不惹眼。懂流程，懂說人話，也懂替別人把麻煩收小。若不是桌上已有那五格熱感欄位，誰都會先鬆一口氣，周祈卻一眼看見他的手。

葉姓職員翻頁時不用拇指壓邊，而習慣用食指和中指一起把紙抬起來，抬高半寸，再往自己這邊折。這動作看著講究，實際最適合順走中間一頁。昨夜館配女人在B1翻 family set 時，也用過這種指法，只是更急。白天的人若把夜裡那套動作磨得更輕一點，便幾乎真成了助人，老太太第一個被他碰上。

他先是笑著說要幫她把補辦文件按新規格排好，又說老人家手抖，自己寫頁數容易漏，願意替她核一次。老太太原本還有些不信，卻被他一句「等會窗口人多，先幫妳減事」說得有點鬆。她剛把文件袋遞出去，周祈已往前半步，把桌上的熱感單推到老太太眼前：「先念。」老太太怔住：「念什麼？」

「妳現在幾頁，哪一頁是關係。」她年紀大，眼花，還是照著念了。四頁。第二頁是關係證明。葉姓職員笑容沒變，只說這樣更好，自己剛好能幫忙標籤。可他把紙拿到桌角時，前台小姐手裡那支筆已落在熱感欄位上：「進場 4 / 經手 葉」。

字一落，葉姓職員手勢果然更輕，也更慢。他不是不敢，是在算。算自己若真照平日那樣做，這一頁會不會剛好被很多眼睛一起看到，林岫鏡頭沒移開。

高哥站在桌左，清潔阿姨靠在後側走道前。藍書包男人抱著書包坐在最亮處，一邊裝作低頭看手機，一邊其實死盯著桌面。葉姓職員終於還是把四頁都整回原位，嘴上還讚一聲前台小姐想得周全。這一局他沒得手。可周祈要的也不是立刻抓贓，而是逼他露出「想動過」這件事，第二個更值錢的差，來得更快。

七點前後，一個穿深藍外套的女人帶著弟弟來補領材料。她手裡文件不多，總共五頁，外加一張夜裡寫好的「家屬在場單」。葉姓職員這回沒再主動碰老太太，卻極自然地對這姐弟說窗口快開了，若肯先去右側小桌填一個「關係確認補問」，等等就能省時間。這說法太順。若不是昨夜那張「front return only if family waiting」還立在桌邊，誰都會覺得合理。前台小姐先問：「右側小桌在哪個流程裡？」葉姓職員笑了一下：「新加的便民表。」

「哪本簿上有？」他一噎，旋即又圓：「內勤剛交代。」周祈走過去，看那張所謂便民表。紙是真的，格式也像平日補填用的白單，最上頭卻只有一行沒有編號的字：「關係補問」。這東西表面是讓人多填一欄，實際最方便的地方在於，它能名正言順把原本連在一起的關係證明與領取頁分開。

「先數。」周祈說。那女人有些緊，卻還是照著數。五頁。弟弟站在她旁邊，困得一直揉眼。葉姓職員接過去，又說小孩站著累，右邊小桌比較安靜。這句話一出口，清潔阿姨直接把清潔車往右側一橫：「那邊剛拖地。」動作土，卻立刻生效。

葉姓職員只好當桌處理。他把便民表壓在原本關係頁上頭，假裝引導欄位。周祈一直盯著他的手，果然看見他在翻到第三頁時，食指先往頁角下頭一勾，像要把中間那張有關係欄的紙悄悄留在自己掌下。這手法太熟，熟到不像臨場起意，而像做過很多次。周祈沒拍他的手，先問那女人：「第三頁是什麼？」她一愣，立刻去看自己剛才放進袋裡的副聯：「關係頁。」

「現在桌上呢？」女人低頭一數，臉色瞬間白了，只剩四頁，整個前台一下靜了。

葉姓職員還想笑著說紙可能粘住，周祈卻已把他手底那張便民表掀開。底下正壓著那張被他勾住半截的關係頁。頁角有新折痕，明顯不是家屬自己折的。弟弟原本還困著，這時卻一下抓住姊姊袖口，像忽然懂了大人們嘴裡說的「帶去後面問兩句」究竟會拿走什麼。

前台小姐這一回沒等誰提醒，直接在熱感欄位重重記下：「進 5 / 離 4 / 葉 / 前燈亮 / 曾提議後側」。記完又補一句：「當桌抓回關係頁」，這一記，比抓到一張紙更重。

因為它證明了這套前台順手不是大家多心，而是真會吃頁。吃的還偏偏是最能把誰等誰、誰算誰、誰有資格站在燈下說清楚的那張。

葉姓職員終於真變了臉，低聲說這是誤會，是流程壓力大，自己只想先分頁方便窗口。可這話一出，大廳幾個剛到的辦事人都露出一種不再願意信的神色。你若只圖方便，為何老是先碰關係頁？

林岫把鏡頭放低，沒拍他的臉，只拍那張被折出新痕的頁角和前台小姐剛寫下的五格熱感單。她知道這比拍一張慌臉更值錢。因為慌臉事後能說是情緒，頁數差卻是誰都看得懂的秤。八點不到，第三個更冷的東西自己露了頭，不是人，是燈。

大廳最亮那口前燈忽然閃了一下，亮度明顯往下沉半格。對別人來說，這不過是老館燈管快壞；對周祈來說，卻像某隻老手終於忍不住從最熟的地方出招。昨夜那張舊複寫頁上明明寫過「子側在前燈，整套暫停」。若父案那一夜真有人先把燈調暗，再把子側、父側和關係頁拆回流程，那麼這口燈就不只是照明，是整條前台回面口的節拍器。他沒等前台小姐去報修，直接踩上椅子把燈罩掀了，裡頭不是新故障。

燈管旁的調光盒上，有一小塊後來補上的薄鋁標，標上印著：「front assist dimmer / manual」。鋁標邊還貼著一張褪色的維修熱感條，條上時間已淡得幾乎看不出，只剩一串編號和一句英文縮寫：「F-LAMP LOW / family assist」。

前台小姐站在下頭看見那句，手都涼了：「這不是普通燈壞，是有人故意留了低光模式。」

高哥立刻把值班維修夾拿來。夾冊裡果然有一列常人根本不會在意的前台燈維修記：哪天左燈閃、哪天右燈換啟動器、哪天大廳全清。最冷的是中間幾筆都只寫同一行：「family assist / lower by hand」。周祈翻到父親那一年附近，指尖猛地一停。那頁上的時間比別的維修條更淡，卻還看得出一筆紅鉛筆補記：「子在前 / 燈先低」，不是完整證據，卻比證據更貼肉。

因為這說明很多年前，至少有人知道當孩子還站在前台時，若想動那一套紙，第一步不是拿人，是先把燈壓低。燈一低，家屬看不清頁數，看不清哪一張被折進去，也更容易被一句「這邊說」引去側邊。

清潔阿姨看見那行字，火氣一下頂上來，乾脆把清潔車上那盞用來照角落污痕的臨時白燈也拖來，插在前台邊上。兩口燈一起亮，大廳桌面白得近乎發硬。她還嫌不夠，又找來一卷螢光膠帶，把前台桌面和後側走道中間硬貼出一道亮線。

「誰家等人，腳都別越過這條線。」她說。這說法粗，卻立刻被大家懂了。老太太的椅子挪到線內，藍書包男人也把書包放到線邊。前台小姐乾脆在新印的「家屬在場單」上再加一句：「位置：前台亮線內」。

葉姓職員看著這一切，終於不再只是尷尬，而像真被什麼逼急了。他說這樣會影響白天流動，前台不是家屬休息區，該交給內勤統一引導。周祈卻只把那張夾著父案年份維修條的夾冊推到他眼前：「誰在做 family assist？」葉姓職員沒答，喉結卻動了一下，這一下值錢得很。

因為它說明這句行話不是單在維修夾裡躺著，它到今天還有人在用。用的人未必就是這個葉姓職員，卻肯定和他熟，熟到他一看便知道惹不得，局部回報在九點真正落下。

前台小姐用那台老熱感機多加了一格頁數欄之後，第一批正式窗口回執開始吐紙。吐到第三張時，周祈忽然看見有一張自動多印了一行極淡的底碼，像老機器滾筒上殘留的舊模板。不是號碼，不是時間，而是一串幾乎融進底灰的字：「front merge / page set」。

他心口一沉，立刻把那張截下來對光。那串底碼只有在低光模式剛切回正常亮度時，熱頭壓力不穩才會露出。也就是說，前台這口燈、這台老熱感機、以及那句 family assist 根本不是零散手段，它們是同一套前台回面工的白日器物。

林岫看著那張底碼，低聲道：「你爸那晚如果真留過紅筆，那他多半也看過這台機器吐出來的影子。」周祈沒接話。

他只是把那張帶底碼的熱感紙和父案年份那張維修條並排夾到透明板上，再在旁邊補了一行最土、卻也最難裝不懂的字：「頁數差多發於前燈轉低後。」大廳裡越來越多人停下來看。

看的人越多，葉姓職員這種手便越難再演成助人。前台小姐也不再只是昨夜那個被嚇出手汗的值台小妹。她已開始主動問每個來等待的人：進場幾頁，誰經手，燈亮不亮，若有人叫去後側，先把名字寫下。這些話一問出口，前台這口燈便不再只是照明，而成了一種白天規矩，周祈知道這還不夠。

底碼露了，頁數差也抓到了，父案那夜的燈被調低過，卻還差最後一隻真正老是把人往後側挪的手。他看向那條被清潔阿姨貼出來的亮線，又看向葉姓職員一直有意無意護著的右側小桌，心裡反而更穩，今夜父案沒全露，但這口燈、這張頁數差、這台熱感機和那隻總愛先碰關係頁的手，已經把下一條白路指得很清。照這條路再往前追，真正該抓的，多半不是誰會說「請去後面坐」，而是誰在燈一低下來時，最習慣把一整套人頁先做成可 merge 的 page set。十點還沒到，前台這套頁數差的笨規矩便已把更多人叫醒了。

不是技術人，不是公司裡那幫開會才會說模型風險的傢伙，而是大廳裡最普通的值班、清潔、早班行政和拿著補件袋坐著等的人。有人開始主動在文件右上角寫頁數；有人一遞交便先問「你別帶我去後側吧」；連兩個本來只來問窗口幾點開的老太太，也學著把自己的「家屬在場單」壓在關係頁上頭，像那張薄薄熱感紙真的能替她們站穩一點位置。

周祈看著這些很土的動作，心裡那股一直燒著的火反倒更穩。黑箱最怕的不是有人看見它一次，是很多白天人突然都懂了，原來哪一張紙最常少、哪一句話最常把你挪走、哪一盞燈一暗下去便最容易讓頁數變得說不清。

葉姓職員被抓了那次當桌順頁後，明顯收斂了，可也更怪。他不再碰關係頁，卻老想替人把「家屬在場單」收進文件袋，嘴上說這樣窗口比較好對件。這也是順手。若在場單不在亮處，而在袋裡，等的人便又能被說成只是一般待辦，不再是「有人就在前燈下等」。周祈於是又加了一條最笨的新規矩：在場單不入袋，必須別在最外。

前台小姐乾脆翻出一盒原本拿來夾號牌的塑膠夾，把每個人的在場單都夾到文件最外面。這做法醜得像夜市寄物，卻立刻把那種最會被「順手收進去」的等待硬拖回了人眼前。老太太夾完自己的單，甚至還摸了摸那塑膠夾，像怕它不牢。她那把年紀，能做的反抗不多，能多夾一個夾子，便算多守住半步。十一點前，真正的第二層頁數差終於露了口，不是葉姓職員，也不是館配女人，而是那台老熱感機旁邊一只平時誰都懶得多看一眼的廢紙盒。

林岫要去換相機電源時，腳尖不小心勾翻了紙盒，裡頭掉出一疊撕得很碎的熱感殘條。碎條本該是垃圾，偏偏有幾張反面仍看得出極淡的頁數欄影子。她把碎條撿起來一拼，竟拼出幾張奇怪的舊格式：上頭沒有「家屬在場」四字，卻有更早期的「front assist」、「wait confirm」，以及一欄後來被取消的「side check」，最要命的是，其中兩張碎條上都留著同一種頁數痕：進場五頁，離場四頁，而經手人欄只有一個極淡的「Q」，周祈看見那個 Q，眼神一下冷了。

不是因為這就能坐實父案，而是這說明頁數差這件事早就不是偶發，更不是單靠某個臨時好心的行政男職員在玩。前台這條白路，從熱感模板那一層起，便早給「頁數可變」留了口。只要經手的是對的那隻手，少一頁便能被磨成白日的噪點。

前台小姐把碎條拼到透明板旁，忍不住罵：「連廢紙盒都知道你們怎麼偷頁。」

清潔阿姨更氣，當場提議連廢紙盒也不准再放桌下。她把紙盒搬到前台正側，用黑筆寫上「熱感廢聯」四個大字，誰撕了什麼、丟了什麼，外頭都看得到。這做法蠢，卻讓那種「反正廢紙誰會看」的偷手立刻少了一個最熟的暗角。

葉姓職員看見那疊拼回來的碎條，臉終於完全變了。他還想說這只是舊模板殘件，周祈卻沒再跟他嘴上繞，直接把那張有「Q」的碎條壓到他面前：「你們白天誰簽 Q？」

葉姓職員沒答，反而先去看大廳右側那只本已關掉的補光燈。那一眼很輕，卻讓周祈立刻記在心裡。因為自打前燈被查出「manual low」之後，右側補光燈這一上午都沒再開。若真有人還想把等待往後側挪，下一步最可能做的，不是再硬帶人走，而是把另一口燈開成「比較舒服」的光，再把桌面頁數慢慢做暗，這一口還沒動，可它已經把下一步自己露出來了。

前台小姐把右側補光燈也記進了新欄位，還在透明板最下方多寫了一句：`燈變，先停頁。`

這句話一貼上去，連大廳裡剛換班來的人都知道了，今晚誰若還想打著方便家屬的名義先動紙，便得先把燈這件小事說清。周祈看著那行字，心裡反而更冷靜，因為他已經聞到了下一隻手的味道。不是葉，也不是昨夜地下那批白手，而是那個最習慣在燈剛一暗時，替所有人說一句「我們去旁邊談」的人。

玻璃門外的天光這時已把大廳地磚照得發白，可前台那口燈仍沒關。它亮得有些笨，也有些刺，卻終於把很多原本只會被人說成「你自己沒看清」的細小差別，照成了誰都能數的頁。

而前台這口燈既然還亮著，今夜誰想再用一句「只是方便」把人頁拆散，便先得學會怎麼從這片亮裡撒謊。更難。。
