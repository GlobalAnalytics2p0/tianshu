# 凌晨三點的演算法素材說明

本資料夾集中保存《凌晨三點的演算法》的作者人格、人物架構、伏筆管理、圖像素材與影音規劃。正式小說正文放在同層的 `文章/`，影音成品只在需要製作時放入根層 `有聲書/`、`影片/`。

## 素材檔案用途

- `核心靈魂檔案.md`：陳停雲的人格、都市科技驚悚、冷幽默與白話黑箱。
- `作者思路.md`：周祈、林岫、死亡推送、確認者與平台權力線。
- `人物架構.md`：主要人物、模型黑箱、家屬與現場職人壓力。
- `每日寫作狀態.md`：最新局勢、下一章可追物與公開場面壓力。
- `伏筆事件台帳.md`：K-0311、確認者、唐曜、母親公寓與權重線索。
- `反思.md`：資深讀者對技術過硬、情緒不足、爽點未公開兌現的直接批評。
- `風格規則.md`：陳停雲專屬節奏、冷笑邊界、反同質化規則。
- `圖像/主角圖片素材/`：周祈與林岫相關視覺素材。
- `有聲書/`、`影片/`：聲音、畫面與媒體方向；目前只保留規劃。

## 續寫定位

所有技術都要壓回人身上。讀者不必懂模型，也要看懂誰被流程吃掉、誰被迫背鍋、周祈如何把黑箱拖到有光的地方。
