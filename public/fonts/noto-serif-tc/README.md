# Noto Serif TC (self-hosted)

天書小說使用 Noto Serif TC Variable 作為小說標題與正文的主要明體。字型檔已依 Unicode 範圍拆成 WOFF2，瀏覽器只會載入目前頁面需要的分段。

- Family used by the site: `Tianshu Serif`
- Upstream family: Noto Serif TC Variable (200–900)
- Font source: [fontsource/font-files](https://github.com/fontsource/font-files/tree/main/fonts/variable/noto-serif-tc)
- Original metadata: [google/fonts](https://github.com/google/fonts/tree/main/ofl/notoseriftc)
- License: SIL Open Font License 1.1; see `OFL.txt`

請保留 `font.css`、`files/` 與 `OFL.txt` 在同一目錄。網站不依賴 Google Fonts 或使用者電腦上的已安裝字型。
